# 📃 Paper-QA 论文问答技能

> 基于 paper-qa (GitHub 27k⭐) 的本地论文PDF问答工具
> 上传论文PDF，问关于论文的任何问题

## 功能

| 命令 | 功能 |
|:----|:-----|
| `问 <PDF路径> "<问题>"` | 对一篇论文PDF提问 |
| `总结 <PDF路径>` | 自动生成论文摘要 |
| `对比 <PDF1> <PDF2>` | 对比两篇论文 |

## 用法示例

```
问 memory/平山书店论文_终稿.docx "这篇论文的核心概念是什么？"
总结 memory/投资者情感_投稿版_2026-06-04.docx
```

## 系统要求

- Python 3.11+（已安装3.14在venv）
- 使用 litellm 调用 LLM（默认使用环境变量配置）
