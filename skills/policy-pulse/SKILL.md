# policy-pulse — 政策脉搏

## 能力
- 自动扫描国务院、发改委、工信部、证监会、央行官网
- 识别政策文件、会议纪要、领导讲话
- 标注利好/利空/中性
- 匹配对应A股板块和标的
- 追踪政策时间线（征求意见→发布→实施）

## 政策分级

| 级别 | 说明 | 影响周期 |
|:----|:----|:--------|
| 🔴 重大 | 国常会/国务院发文 | 1-3个月 |
| 🟡 中等 | 部委规章/行业标准 | 1-4周 |
| 🟢 一般 | 地方政策/领导讲话 | 3-7天 |

## 数据源
| 来源 | 地址 | 频率 |
|:----|:----|:----|
| 国务院 | gov.cn | 每日 |
| 发改委 | ndrc.gov.cn | 每日 |
| 工信部 | miit.gov.cn | 每日 |
| 证监会 | csrc.gov.cn | 每日 |
| 央行 | pbc.gov.cn | 每日 |

## 输出格式
```
📋 【政策脉搏】YYYY-MM-DD

🔴 重大政策：
  - 标题：XXX
  - 来源：国务院
  - 影响板块：XXX
  - 利好/利空：🟢利好
  - 影响周期：1-3个月

🟡 中等政策：
  - 标题：XXX
  - 来源：工信部
  - 影响板块：XXX
  - 利好/利空：🟢利好

📅 待落地事件：
  - X月X日：XX会议
  - X月X日：XX法规实施
```

## 触发场景
- 盘前简报
- 盘中政策发布提醒
- 持仓股相关政策变化预警
