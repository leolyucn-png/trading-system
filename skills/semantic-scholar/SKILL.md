# 🎓 Semantic Scholar 论文搜索技能

> 基于 Semantic Scholar 免费 API 的学术论文搜索 + 引用网络

## 功能

| 命令 | 功能 |
|:----|:-----|
| `搜索 <关键词>` | 搜论文（标题+摘要） |
| `推荐 <论文ID>` | 推荐相关论文 |
| `引用 <论文ID>` | 查看引文网络 |

## 用法示例

```
搜索 affective publics China platform
搜索 investor sentiment social media
推荐 10.1177/14614448221079000
```

## 注意

- API免费，限速100 req/s
- 需要API Key可提升限额（免费注册）
