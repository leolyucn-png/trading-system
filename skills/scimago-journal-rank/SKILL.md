# 📊 Scimago 期刊排名查询技能

> 查询 SSCI/SCI 期刊分区、影响因子、排名

## 功能

| 命令 | 功能 |
|:----|:-----|
| `排名 <期刊名>` | 查期刊 SJR 排名+分区 |
| `学科 <学科名>` | 查某学科 Q1-Q4 期刊列表 |
| `对比 <期刊A> <期刊B>` | 对比两本期刊的排名引用指标 |

## 用法示例

```
排名 New Media and Society
排名 Convergence
学科 Communication
对比 Convergence Journal of Communication
```

## 数据来源

- 基于 Scimago Journal Rank (SJR) 数据库
- 覆盖 34,000+ 期刊
- 学科分类按 Scopus 标准
