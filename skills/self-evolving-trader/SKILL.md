# 自我进化交易系统

## 核心能力

### 1. 记忆保存 🧠
自动记录每笔交易操作、结果、决策理由。
- 持仓变更 → 写入 `memory/trades.md`
- 每日复盘 → 写入 `memory/交易日志/YYYY-MM-DD.md`
- 关键发现 → 追加到 `memory/经验教训库.md`

### 2. 经验提取 🔍
从交易结果中提取可复用的模式：
- ✅ 盈利交易 → 提取成功条件，验证可重复性
- ❌ 亏损交易 → 分析失败原因，追加禁止规则
- 📌 新发现 → 即时追加到框架

### 3. 框架迭代 🔄
- 读取经验教训库 → 提炼核心原则
- 更新汉武帝计划 → 进化到下一版本
- 每个交易日自动执行一次进化循环

## 进化循环流程

```bash
# 每日收盘后执行
python3 skills/self-evolving-trader/scripts/daily_review.py
```

## 输出
- `memory/经验教训库.md` — 所有已发现模式的索引
- `memory/交易日志/YYYY-MM-DD.md` — 每日详细复盘
- `memory/汉武帝计划.md` — 持续进化的主框架
