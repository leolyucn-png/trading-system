# 提前埋伏预扫描 Pipeline

每晚美股收盘后自动运行，通过美股走势预判明日A股方向。

## 三个模块

### 模块1：美股→A股映射 🌙
扫描美股科技龙头和中概股收盘，映射到A股受益板块。

### 模块2：资金异动扫描 📊
扫描A股当日量比>3但涨幅<3%的票（聪明钱已进，股价未动）。

### 模块3：新闻信号扫描 📰
抓取财联社/Reuters关键新闻，评估对A股的影响天数和时机。

## 输出格式
推送到Telegram，包含：
- 今日美股方向
- 明日A股预判板块
- 候选埋伏清单（代码+价格+逻辑）
- 风险提示
