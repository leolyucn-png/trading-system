# capital-flow-monitor — 资金流向监控

## 能力
- 北向资金：每日净流入/流出，连续N日趋势
- 主力资金：超大单/大单净流入
- 板块资金：行业资金流向排行
- 龙虎榜：游资动向、机构席位
- 成交量异动：量比>3、换手率突变

## 资金信号

| 信号 | 含义 | 操作参考 |
|:----|:----|:--------|
| 北向连续3天净流入板块X | ✅ 聪明钱建仓 | 关注板块X个股 |
| 主力单日净流入>5亿个股 | ⚠️ 大资金进场 | 但需确认非出货 |
| 龙虎榜机构净买入>1亿 | ✅ 机构认可 | 中线参考 |
| 量比>5且涨幅<1% | 🔥 异常放量 | 可能有未公开消息 |

## 数据源
- 东方财富资金流
- 同花顺DB
- 腾讯API量比数据

## 输出格式
```
💰 【资金监控】YYYY-MM-DD

北向资金：
  - 今日净流入：XX亿（连续X日净流入）
  - 重点买入板块：X、Y、Z

主力资金：
  - 净流入TOP3板块：X/X亿、Y/Y亿、Z/Z亿
  - 净流出TOP3板块：X/X亿、Y/Y亿、Z/Z亿

量价异动：
  - 标的A：量比4.5 涨幅0.3%（异常放量）
  - 标的B：换手率翻倍 股价横盘

龙虎榜（前日）：
  - 机构买入TOP：XXX
  - 游资活跃：XXX
```

## 触发场景
- 盘前简报
- 盘中异动
- 持仓股资金异常变化提醒
