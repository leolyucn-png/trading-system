## 核心速查

### 选股条件（必须同时满足）
```
市值：50亿~200亿
换手率：3%~15%
均线：20日均线上方
北向：连续3天加仓
```

### 排除清单（碰都不碰）
```
ST股 · 连续2年亏损 · 市值>500亿 · 换手率>20% · 股东暴增50%+ · 董事长频繁减持
```

### 操作纪律
```
不长期持有 · 不看财报选股 · 不追热点
不在上午买入 · 不在尾盘前买入
大盘跌>2%空仓 · 空仓不是踏空
```

### GATE 0~3
```
GATE 0：大盘可不可操作？（北向/涨停家数/连板/跌幅/尾盘）
GATE 1：股票合不合格？（市值/换手率/20日线/排除清单/北向）
GATE 2：事件对不对？（政策第一天/不是追热点）
GATE 3：执行合规？（尾盘/仓位/止损）
```
