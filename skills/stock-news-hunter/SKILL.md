# stock-news-hunter — 板块新闻轮动

## 能力
- 每日扫全市场各板块新闻（同花顺/东方财富行业板块）
- 识别热点题材和轮动方向
- 标注已发酵/未发酵
- 追踪板块资金流入流出

## 数据源
| 来源 | 地址 | 用法 |
|:----|:----|:-----|
| 财联社电报 | cls.cn | 实时新闻，只看标题 |
| 同花顺板块 | 10jqka.com.cn | 板块涨幅排行 |
| 东方财富行业 | eastmoney.com | 行业资金流向 |

## 输出格式
```
📡 【板块轮动】YYYY-MM-DD

🔥 已发酵（追高风险）：
  - 板块A：涨幅X%，资金流入Y亿，已持续Z天
  
🟢 未发酵（关注标的）：
  - 板块B：涨幅X%，资金刚启动，新闻量少

📊 轮动方向判断：
  - 风格：大盘/小盘/成长/价值
  - 主线：XXX
  - 支线：XXX
```

## 触发场景
- 盘前简报
- 盘中实时预警
- 用户问"今天什么板块在动"
