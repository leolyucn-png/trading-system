# 市场情绪温度计

## 概述

本技能用于量化A股市场情绪，为GATE 0大盘判定提供数据支撑。
核心逻辑：市场情绪不是"感觉"出来的，是算出来的。

---

## 计算公式

```
情绪温度 = 涨停家数分 × 40% + 跌停家数分(反向) × 30% + 涨跌比分 × 20% + 连板高度分 × 10%
```

### 分项计算规则

#### 涨停家数分
| 涨停家数 | 得分 | 市场状态 |
|:--------|:---:|:--------|
| ≤20家 | 10分 | 冰点，无人问津 |
| 21-40家 | 30分 | 冷清，局部热点 |
| 41-60家 | 50分 | 常温，有赚效应 |
| 61-80家 | 70分 | 温热，全面活跃 |
| >80家 | 90分 | 高潮，亢奋状态 |

#### 跌停家数分（反向）
| 跌停家数 | 得分 | 市场状态 |
|:--------|:---:|:--------|
| >80家 | 10分 | 股灾级恐慌 |
| 61-80家 | 20分 | 系统风险 |
| 41-60家 | 40分 | 局部风险 |
| 21-40家 | 60分 | 正常调整 |
| ≤20家 | 80分 | 健康盘面 |

#### 涨跌比分
直接映射：涨跌比 = 1:1 → 50分, 3:1 → 75分, 1:3 → 25分
计算公式：`涨跌比分 = 涨家数 / (涨家数+跌家数) × 100`

#### 连板高度分
| 最高连板 | 得分 | 说明 |
|:--------|:---:|:----|
| ≤2板 | 10分 | 无赚钱效应，恐高的市场 |
| 3板 | 30分 | 试探期，存在分歧 |
| 4-5板 | 50分 | 正常空间板 |
| 6-7板 | 70分 | 龙头出现，格局打开 |
| >7板 | 90分 | 妖股横行，情绪极亢奋 |

## 温度 → GATE 0 映射

| 温度区间 | 状态 | GATE 0 | 短线仓位 |
|:--------|:----|:------|:--------:|
| 0-20分 | 🔵 **冰点** | 🟢 **绿灯** — 冰点抄底窗口 | 70% |
| 21-40分 | 🟢 **低温** | 🟢 **绿灯** — 可操作 | 50% |
| 41-60分 | 🟡 **常温** | 🟡 **黄灯** — 谨慎 | 30% |
| 61-80分 | 🟠 **高温** | 🔴 **红灯** — 减仓 | 20% |
| 81-100分 | 🔴 **高潮** | 🔴 **红灯** — 空仓 | 10% |

## 数据源

| 数据 | 接口 | 说明 |
|:----|:----|:-----|
| 涨停家数 | 东方财富涨停板API | 获取今日涨停/跌停总数 |
| 涨跌家数 | 东方财富大盘统计 | 获取沪深两市上涨/下跌家数 |
| 连板高度 | 东方财富连板统计 | 获取市场最高连板数 |
| 北向资金 | 东方财富资金流 | 辅助判断（北向持续流入=偏暖） |

## 调用方法

### 方式一：自动拉取+计算

```python
# 伪代码流程
def get_market_sentiment():
    涨停家数 = fetch_limit_up_count()       # API拉取
    跌停家数 = fetch_limit_down_count()     # API拉取
    涨家数, 跌家数 = fetch_market_breath()  # API拉取
    最高连板 = fetch_highest_board()         # API拉取
    
    温度 = 计算情绪温度(涨停家数, 跌停家数, 涨家数/跌家数, 最高连板)
    GATE_0 = 温度转GATE(温度)
    
    return {"温度": 温度, "GATE_0": GATE_0, "仓位建议": 仓位映射[温度]}
```

### 方式二：手动估算（API不可用时）

```
1. 打开同花顺/东方财富行情页
2. 找到"涨跌家数/涨停跌停"数据
3. 按公式手动估算
4. 输出GATE 0判断
```

## 注意事项

1. 温度计是量化参考，不是绝对真理。极端行情（如2024年春节前）可能失真
2. 冰点≠不能做，是抄底窗口；高潮≠不能涨，但风险极高
3. 北向资金作为辅助修正因子：北向持续流入可+5分，持续流出可-5分
4. 数据源建议10分钟刷新一次，避免使用过期数据
