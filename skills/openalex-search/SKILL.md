# 📚 OpenAlex 学术搜索技能

> 基于 OpenAlex 免费 API 的学术论文搜索 + 引用网络分析
> 覆盖 2.5 亿+ 论文，完全免费，无需 API Key

## 功能

| 命令 | 功能 |
|:----|:-----|
| `搜索 <关键词>` | 按标题/摘要搜索论文 |
| `引用 <论文ID>` | 查看引用该论文的文章 |
| `被引 <论文ID>` | 查看该论文引用的参考文献 |
| `作者 <作者名>` | 搜索某作者的全部论文 |
| `相关 <论文ID>` | 基于概念推荐相关论文 |
| `期刊排名 <期刊名>` | 查看期刊的 h-index/引用指标 |

## 用法示例

```
搜索 affective publics 2020-2025
搜索 中国 平台 算法 可见性
引用 W4281552200
相关 10.17645/mac.v10i2.5057
作者 Zhongwang Lyu
期刊排名 New Media & Society
```

## 技术细节

- API: https://api.openalex.org
- 限速: 10 req/s（无key），100k req/d（有key，免费注册）
- 数据覆盖: 250M+ works, 200k+ journals, 20M+ authors
- 响应时间: ~100-300ms
