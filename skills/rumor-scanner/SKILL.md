# rumor-scanner — 早期信号扫描

## 能力
- 扫描雪球/微博/股吧/知乎等平台的早期讨论
- 识别机构调研密集但股价未动的标的
- 追踪龙虎榜游资动向中的新面孔
- 关联同一产业链不同环节的联动信号

## 数据源
| 来源 | 用法 |
|:----|:-----|
| 雪球 | 讨论热度+个股话题量变化 |
| 东方财富股吧 | 帖子量骤增的标的 |
| 机构调研数据 | 单周调研>50家但股价没涨 |
| 龙虎榜 | 游资新席位动向 |
| 成交量异动 | 量比>3但涨幅<2% |

## 早期信号分级

| 级别 | 说明 | 置信度 |
|:----|:----|:------|
| 🔴 强信号 | 调研+资金+量价三共振 | 70%+ |
| 🟡 中信号 | 2个指标同步 | 50-70% |
| 🟢 弱信号 | 单个指标异动 | 30-50% |

## 输出格式
```
🕵️ 【早期信号】YYYY-MM-DD

🔴 强信号：
  - 标的X：单周80家调研+北向连续3天加仓+股价没涨

🟡 中信号：
  - 标的Y：量比4.2涨幅0.5%，异常放量

🟢 弱信号：
  - 板块Z：雪球讨论量+40%，无新闻解释
```

## 触发场景
- 盘前简报中的"潜在机会"部分
- 盘中异动提醒
