# 板块龙头识别器

## 概述

本技能用于识别A股各板块的真正龙头股。
核心逻辑：**真龙头有定价权，跟风票只能涨价时跟涨。**

旭光为什么是龙头？因为它大盘跌时涨停（独立走势），不是板块涨它才涨。

---

## 龙头识别五维模型

### 维度一：行业地位（权重25%）

| 指标 | 真龙头 | 跟风票 |
|:----|:------|:------|
| 市场份额 | 国内前三 | 前十开外 |
| 定价能力 | 能主导行业价格 | 只能接受市场价格 |
| 客户认证 | 进入顶级客户供应链（如华为/特斯拉/台积电） | 供应二三线厂商 |
| 专利壁垒 | 核心专利群，竞争对手难以绕过 | 无核心技术，组装为主 |

**检查方法：** 查年报"核心竞争力"章节 + 同花顺F10经营分析 + 互动易客户披露

### 维度二：供应链地位（权重20%）

| 指标 | 真龙头 | 跟风票 |
|:----|:------|:------|
| 上下游溢价权 | 上游能压价，下游能提价 | 两头受挤压 |
| 客户集中度 | 合理分散（前5大客户<50%） | 过度依赖单一客户 |
| 供应商门槛 | 供应商认证周期长（1-3年），客户不会轻易换 | 轻易可替代 |

**本质问题：** 如果明天这个公司倒闭了，它的客户能不能找到替代供应商？
- 找不到 → 真龙头 ✅
- 随便找 → 跟风票 ❌

### 维度三：资金认同（权重20%）

| 指标 | 真龙头 | 跟风票 |
|:----|:------|:------|
| 机构持仓 | 前十大有公募/社保/保险，合计>20% | 机构寥寥，散户扎堆 |
| 北向资金 | 沪/深股通持续净买入 | 无北向或进出不定 |
| 龙虎榜 | 机构席位买入 > 卖出 | 全是散户席位 |
| 股东人数 | 持续下降，筹码集中 | 持续上升，筹码分散 |

### 维度四：独立走势（权重20%）

**本质：真龙头可以不看板块脸色。**

| 信号 | 含义 |
|:----|:-----|
| 板块涨它涨更多 | 基础分，还没证明自己 |
| 板块跌它横盘 | 有资金护盘 🟡 |
| **板块跌它反涨** | **真龙确认 🟢** |
| 大盘跌它涨停 | **最强信号 🚀** |

**判断方法：** 取最近10个交易日，比较个股涨跌幅 vs 板块指数涨跌幅。
- 个股涨幅 > 板块涨幅 × 1.5 = 基础龙
- 个股跌幅 < 板块跌幅 × 0.5 = 抗跌龙
- 板块跌>2%但个股收红 = 真龙

### 维度五：赛道想象力（权重15%）

| 类型 | 例子 | 评分 |
|:----|:----|:---:|
| 万亿级市场+国产替代刚起步 | 碳化硅/先进封装/AI算力 | ⭐⭐⭐⭐⭐ |
| 千亿级市场+政策驱动 | 低空经济/核聚变/军工 | ⭐⭐⭐⭐ |
| 百亿级市场+细分龙头 | 特种材料/工业母机 | ⭐⭐⭐ |
| 成熟市场+跟随者 | 普通PCB/普通化工 | ⭐⭐ |
| 夕阳行业 | 纯煤炭/纯纺织 | ⭐ |

## 龙头分类

| 类型 | 特征 | 操作策略 |
|:----|:----|:--------|
| 🚀 **趋势龙头** | 机构打底+游资催化，走大趋势 | 按大趋势牛股框架持有 |
| 🔥 **情绪龙头** | 纯游资炒作，连板为主 | 短线快进快出，不格局 |
| 🛡️ **防御龙头** | 机构重仓，低波动高股息 | 大盘弱势时的避风港 |
| 💀 **蹭概念** | 板块涨它跟一点，板块跌它先砸 | 不碰 |

## 识别流程

```
Step 1: 确定板块
  从stock-sector-hunter获取今日强势板块榜单

Step 2: 扫描板块内个股
  拉取同花顺板块成分股列表

Step 3: 用五维模型评分（每个维度1-10分）
  总分 = 行业地位×25% + 供应链×20% + 资金认同×20% + 独立走势×20% + 赛道×15%
  
  ≥8.0分  → 真龙头 ✅
  6.0-7.9 → 一线跟风 🟡（板块涨时可用）
  <6.0   → 蹭概念 ❌（不碰）

Step 4: 交叉验证
  对比同板块其他热门票的评分，排序出真龙头

Step 5: 对接诸葛亮
  龙头评分 → 进入候选池
  跟风票 → 剔除
```

```
  XXX（评分4.5）— 无实质业务
  XXX（评分3.2）— PE亏损+无机构

━━━━━━━━━━━━━━━━━━
```

## 注意事项

1. **不要只看市值**——市值最大的不一定是最真的龙头（如三大运营商市值大但弹性差）
2. **区分"板块龙头"和"细分龙头"**——宁德是电池板块龙头，但不是锂矿龙头
3. **龙头会换**——每个阶段都有新的龙头，不要死守旧龙头
4. **旭光为什么是真龙头**——因为它有独立的走势、稀缺的技术、顶级客户、持续的资金流入
5. **新龙头的特征**——往往在板块沉寂时默默走强，等板块爆发时它已经涨了50%
