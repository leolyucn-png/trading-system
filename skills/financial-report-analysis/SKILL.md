# financial-report-analysis — 财报解析

## 能力
- 自动抓取上市公司财报关键数据
- 同比/环比分析
- 毛利率/净利率/ROE趋势
- 现金流健康度评估
- 风险点标注（应收账款/商誉/负债率/存货）

## 关键指标

| 维度 | 指标 | 预警线 |
|:----|:----|:------|
| 利润 | 营收同比/环比、净利润、扣非净利润 | 连续2季下滑=⚠️ |
| 盈利 | 毛利率、净利率、ROE | ROE<5%=⚠️ |
| 现金 | 经营现金流、自由现金流 | 经营现金流为负=⚠️ |
| 风险 | 应收账款/营收比、商誉/净资产比、负债率 | 商誉>30%净资产=⚠️ |
| 增长 | 营收增速、利润增速 | 增速放缓=⚠️ |

## 数据源
- 东方财富F10
- 同花顺F10
- 新浪财经财报

## 输出格式
```
📊 【财报解析】{公司名} ({财报周期})

✅ 亮点：
  - 营收X亿 同比+XX%
  - 毛利率XX% 环比+XX%

⚠️ 风险点：
  - 商誉X亿 占净资产XX%
  - 经营现金流为负

📈 趋势判断：
  - 盈利改善/恶化/平稳
  - 成长性：强/中/弱
```

## 触发场景
- 用户查询某公司财报
- 财报发布日自动解析持仓股
- 季报/年报季批量扫描
