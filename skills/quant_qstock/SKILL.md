# 细分赛道量化计算器 qstock 配套

## 安装
```bash
pip install qstock
```

## 核心能力

### 能力一：概念板块实时行情
```python
import qstock as qs

# 概念板块涨跌幅排行
df = qs.concept_top()
print(df.head(10))
```

### 能力二：概念板块历史走势（计算相对强度）
```python
# 获取概念板块历史K线
# 注意：qstock的概念板块API需要概念代码
df = qs.get_data('concept_code')
```

## 输出格式

```
📊 【细分强度扫描】YYYY-MM-DD

🟢 相对强度TOP10（个股vs所属板块）：

🔴 逆势异动（大盘跌它不跌）：
```
