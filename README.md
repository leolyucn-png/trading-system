## 📊 模型职责

| 模型 | 职责 | 数据源 |
|:----|:-----|:-------|
| **秦始皇** | 大盘健康度八维评分 + GATE门控 + 概率交易系统 | 沪深300/上证/涨跌比 |
| **关羽** | 资金扫描 + ETF全表(38个) + 北向资金 + 龙虎榜 + 龙头识别 | 新浪/腾讯/东财 |
| **刘备** | 国内三源排雷(东财/新浪/同花顺) + 海外三源预测(Reuters/Bloomberg/BBC) | RSS+Google News |
| **张飞** | 20日价格分位 + 量价四象限判定 + 五大情绪指标 + 仓位联动 | akshare ETF日K |
| **刘彻** | T+1隔日套利 — 板块甄别→个股筛选→防幻觉自检→尾盘执行 | 腾讯行情/qt.gtimg.cn |
| **诸葛亮** | 中长期牛股筛选 — 五维DNA + 独立走强 | akshare |
| **孙权** | 超短线龙头模式（10%资金，情绪周期优先） | — |
| **赵云** | 每日复盘归因 — 正确/卖飞/止损/追高分类 | 交易日志 |

## 🔄 核心原则

1. **概率推断 > 因果推理** — 不编"因为所以"，只算"历史上胜率多少"
2. **数据驱动** — 所有判断必须有实时行情数据支撑，禁止脑补
3. **分层风控** — 秦始皇GATE→张飞板块拦截→刘彻防幻觉自检
4. **自我校准** — 每笔交易后更新概率矩阵（贝叶斯更新）
