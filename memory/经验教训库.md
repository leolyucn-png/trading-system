## 🆕 2026-07-15 — 【用户原创观察·编号E001】财报走势由预支程度决定，非财报正负

### 案例三枚钉死

```
① 大恒科技: 公告前+35% → 业绩扭亏为盈(正) → 公告日跌停 💀
   （利好在33%涨幅中已被完全预支）

② 完美世界: 公告前阴跌 → 业绩亏损(负) → 公告后反涨 +3.5%
   （亏损已被阴跌预支，落地=利空出尽）

③ 天通股份: 公告前阴跌 → 业绩亏损(负) → 公告后反涨 +4.19%
   （同上逻辑）
```

### 核心结论

```
决定涨跌的不是财报本身(正/负)，而是财报前的预支程度(已涨/已跌)
公告前暴涨+利好落地=出货候选(反向规避)
公告前超跌+财报落地(无论正负)=利空出尽候选
```

### 关联规则（三问核查清单加注参照）

本观察是三组已注册规则的理论根：
  - 规则R01: 公告前10日涨幅>20%标"预期透支"（源头在此）
  - 规则R02: 扣非占比<70%降级（利好质量审计，防伪利好）
  - 规则R03: 风险提示公告核查（公司自己预警=危险信号）

三问核查清单头部加注: **"参照经验教训库E001——涨跌看预支程度，不看财报正负"**

## 🔴 2026-06-10 — 最关键的教训：做T不是加仓，是套利

### 做T的核心定义

> **做T = 买入新股 + 卖出旧仓 | 当日完成 | 净敞口不变**

做T不是加仓。做T是套利——利用持仓做日内回转，不增加总风险敞口。

### 做T vs 加仓 的本质区别

| 维度 | 做T | 加仓 |
|:----|:----|:----|
| 目的 | 套取日内差价，降成本 | 增加仓位赌方向 |
| 净敞口 | 不变（买新=卖旧） | 增加 |
| 风险 | 日内波动风险 | 隔夜持仓风险 |
| 时间 | 当日完成 | 持续持有 |
| 现金消耗 | 先消耗，当日回收 | 永久消耗 |

**做T的精髓：新买的和旧仓的两笔互相对冲，赚的是差价，不是赌方向。**

```

④ 散户在干什么？
```
