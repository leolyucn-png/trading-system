## 一、张飞仓位联动规则（新增）

张飞每日盘后计算板块/ETF的分位+量价+情绪，输出三档仓位建议供秦始皇GATE和龙虾使用。

### 高位预警 → 限制加仓

| 触发条件 | 动作 |
|:--------|:-----|
| 持仓板块被标记🟡高位预警 | 该板块相关标的**禁止新开仓** |
| 总持仓中≥3个板块在高位区 | 总仓位上限降至**50%**（覆盖GATE） |
| 高位+放量滞涨+情绪过热 | 触发🔴风险拦截，强制减仓该板块1/3持仓 |

### 低位机会 → 进观察池

| 触发条件 | 动作 |
|:--------|:-----|
| 板块被标记🟢低位机会 | 推送给刘彻候选池，标记"张飞低位信号" |
| 低位+缩量企稳+情绪指标支持 | 优先级提升至候选池前3 |
| 低位+放量启动+情绪指标支持 | **可开仓信号**（直接进入可执行候选）|

### 中段无限制

| 条件 | 动作 |
|:----|:-----|
| 所有中段板块 | 不做任何风控拦截 |
| 连板豁免标的（走中段规则） | 也不做拦截，只输出人气温度 |

## 二、监控铁律

```
张飞刘备的任务不只是早上给预判
→ 必须在盘中持续监控，触发信号时主动报警
→ 不能等用户来问才分析
→ 张飞每90分钟刷新一次（09:30/11:00/13:30/14:25）
→ 刘备只在有异动时触发舆情验证（不刷屏）
```

## 三、触发规则（满足任一条→立即报警）

### 🔴 大盘级风险

| 触发条件 | 动作 |
|:--------|:----|
| 上证/创业板 13:00后加速下跌>1.5% | 🚨 张飞报警：下午加速杀跌 |
| 科创50跌破早盘低点 | 🚨 踩踏信号 |
| 北向单日净流出>50亿 | 🚨 外资撤退 |
| 跌停家数>50 | 🚨 恐慌扩散 |
| 张飞高位预警+大盘同步走弱 | 🚨 双重确认，强制减仓 |

### 🟡 持仓级风险

| 触发条件 | 动作 |
|:--------|:----|
| 单票日内跌幅>5%（没有利空） | ⚠️ 检查是否补跌 |
| 单票跌幅>7% | 🔴 强制止损评估 |
| 3只以上持仓同时跌>3% | ⚠️ 板块级风险 |
| 持仓从翻红变翻绿（振幅>5%） | ⚠️ 资金在撤 |
| 持仓板块被张飞标记🔴风险+跌幅>2% | ⚠️ 张飞风险确认，考虑减仓 |

### 🟢 机会级信号

| 触发条件 | 动作 |
|:--------|:----|
| 持仓从-5%→翻红（独立修复） | 💡 资金在进场 |
| 板块逆大盘放量涨 | 💡 独立方向确认 |
| 张飞标记🟢低位机会+板块翻红 | 💡 张飞机会确认，入候选池 |
| 张飞标记低位+刘备验证无利空 | 💡 双重确认，可直接关注买入 |
| **银行+保险同时放量上涨** | 🚨 **用户亲授：盘面不好的信号**，防御启动=风险资产承压 |

## 四、张飞刘备联动流程

```
张飞定时扫描（每90分钟）
     ↓
输出板块量价判定 + 分位 + 情绪
     ↓
┌─ 是否触发预警/机会？ ─┐
│ 是                     │  否
│   ↓                    │  → 不触发刘备
│ 刘备验证舆情          │
│   ↓                    │
│ 刘备输出验证结果      │
│   ↓                    │
│ 联动动作：             │
│  🔴→限制加仓/强制减仓  │
│  🟢→进候选池/可开仓     │
└────────────────────────┘
```
