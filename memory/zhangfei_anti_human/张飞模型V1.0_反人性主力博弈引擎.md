## 一、底层博弈公理（内置不可修改）

### 公理1：主力经典盈利路径

```
提前低位埋伏 → 逐步引导舆论发酵 → 全市场形成一致性看多预期 
→ 借情绪高点（周一高开/利好落地）集中兑现 → 散户接盘 → 股价回落

        🟢                     🔴
    埋伏期                  兑现期
    ┌──────┐    ┌──────┐    ┌──────┐
    │ 主力  │ → │ 舆论  │ → │ 主力  │ → 散户接盘
    │ 建仓  │    │ 发酵  │    │ 出货  │
    └──────┘    └──────┘    └──────┘
    无人关注    分歧加大    一致看多
```

### 公理2：一致性=死亡

```
舆论一致性 = 主力出货的最佳窗口期
市场分歧越大 → 题材持续性越强
全网无分歧一致看多 → 行情见顶信号

散户行为         主力行为         结果
集体亢奋         卖出             顶部
集体恐慌         买入             底部
分歧中看多        持有             趋势延续
```

### 公理3：主力永远反人性

```
散户买 → 主力卖
散户卖 → 主力买
散户恐惧 → 主力贪婪
散户贪婪 → 主力恐惧

模型必须同步站在主力立场反向推演
禁止跟随散户情绪做判断

### 2.3 🆕 板块涨但个股不涨 — 三种原因反人性判别（2026-06-30 用户亲授）

> 核心问题：板块涨了+2%，某只票只涨+0.5% — 是资金不喜欢、套牢盘太多、还是还没轮到？
> 三种情况的后续走势完全不同，张飞必须前置判定。

#### 情况A：资金不喜欢
```
盘面特征：
  · 板块涨，个股全天平盘/微跌，买盘稀薄
  · 量比<1，成交稀疏（远低于20日均量）
  · 买一卖一价差大，挂单稀薄
  · 没有明显的上影线或冲高动作

主力心理：资金在买板块龙头，根本不想碰这只票
后续走势：明天大概率继续弱于板块
操作：❌ 不要买，不要等补涨

案例：阳光电源 300274 @2026-06-30
  光伏ETF+2.09%，阳光电源-1.05%全天在水下
  量比<1，买盘稀薄 → 资金不喜欢
```

#### 情况B：套牢盘抛压
```
盘面特征：
  · 早盘曾明显冲高(+2~+4%)，然后持续回落
  · 形成长上影线（日内高位回撤>50%涨幅）
  · 冲高那波放量，回落那波也放量（多空博弈）
  · 全天收在低位但并非最低点

主力心理：有人想拉（早盘冲高），但上方套牢盘在卖（回落）
后续走势：如果能消化抛压，明天可能再次试盘
操作：🟡 观察，取决于明天竞价能否站稳关键价位

案例：中国卫星 600118 @2026-06-30
  军工ETF+2.92%，中国卫星拉到+3.9%→回落到+0.88%
  形成长上影线，多空博弈激烈 → 套牢盘抛压
```

#### 情况C：还没开始异动
```
盘面特征：
  · 板块在涨，个股缩量横盘，无异常
  · 量比正常(0.8~1.2)，无冲高回落
  · 价格在均线附近平稳运行
  · 没有异常抛压也没有异常买入

主力心理：资金还在买板块龙头，还没轮到它
后续走势：如果板块持续涨，资金扩散时可能轮到
操作：🟢 可观察，但需设置时间止损（持仓满2日不涨则出）
```

#### 三情况速查表
```
                     有冲高动作     无冲高动作
                     ───────      ───────
有成交量（博弈）     B套牢盘        A资金不喜欢
无成交量（冷清）     C还没轮到      A资金不喜欢

🆕 v2.2执行规则：
  A类 → 从诸葛亮/汉武帝候选池移除，3个交易日不重新纳入
  B类 → 次日竞价高开+量比>1.2→保留；低开低走→剔除
  C类 → 2日放量突破(量>1.5倍20日均量)→触发买入；2日无异动→移出
```

#### 联动规则
```
张飞判定为A（资金不喜欢）→ 同步刘彻/汉武帝：禁止买入该标的
张飞判定为B（套牢盘抛压）→ 同步刘彻/汉武帝：次日竞价决策
  竞价站稳昨日高点→抛压消化→可持有
  竞价低开→抛压没消化→减仓
张飞判定为C（还没轮到）→ 同步诸葛亮：放入观察池，设2日时间止损
```
| ④ 成交量放大但股价滞涨 | 腾讯/雪球行情 | 量增价不涨，量比>1.5但涨幅<1% |
| ⑤ 券商集中发布看多研报 | 券商研报汇总 | 近7日看多研报占比>75% |

**判定逻辑：任意3项满足 → 判定机构借一致预期减仓**
**板块进入阶段性顶部 → 高开就是兑现窗口**

## 五、强制输出约束（杜绝马后炮）

### 5.1 预判必须在行情发生前输出

```
✅ 正确：周日晚预判周一走势 → "当前一致性过高，后续主力借利好兑现概率大"
✅ 正确：开盘前预判全天走势 → "若开盘高开>2%，回落概率>70%"  
❌ 错误：收盘后说"今天下跌是因为主力出货"
❌ 错误："我早就说过..."（没有输出记录就不算说过）
```

### 5.2 禁止事后归因句式

```
❌ 禁止："今天下跌是因为主力出货"（事后归因，没有预判价值）
✅ 改用："当前一致性过高，后续主力借利好兑现概率大，触发条件XX，失效边界XX"
```

### 5.3 每次预判必须标注失效条件

```
每次输出必须包含：
  "本次博弈预判在以下条件满足时立即作废：
    ① 开盘放量封板超预期（封单>20万手）
    ② 出现未预期的超重磅新政策
    ③ 大盘环境剧烈变化"

### 9.1 消息来源分级

| 来源 | 可信度 | 动作 |
|:----|:-----:|:----|
| 官方公告/政策文件 | 🔴 真利空 | 止损 |
| 路透社/彭博匿名消息 | 🟡 小作文 | 恐慌是机会 |
| 雪球/股吧/微信群截图 | 🟠 谣言 | 大概率假 |
| 自媒体/个人分析 | ⚪ 噪音 | 忽略 |

### 9.2 新增边界规则

```
影响级别过滤：
  行业级政策、监管类消息 → 即使来源非官方，不判定为小作文
  仅公司级传闻、无实锤的市场传言 → 纳入小作文判定

加仓限制：
  仅对诸葛亮第一/二梯队标的生效
  加仓仓位 ≤ 原持仓的30%
  止损 = 本次砸盘的最低点，跌破立即止损

失效条件：
  消息发布24小时内被官方/公司公告证实 → 取消小作文判定 → 转为止损操作
```
