# 🗡️ 张飞模型 V2.0 — 轮动预测模块

> 版本：v2.0 | 建立：2026-07-01 10:10
> **张飞模型双功能：反人性博弈 + 轮动时序预测**
> 定位：提前2天识别轮动信号，Day -1就确认，不等Day 0

---

## 一、核心规则

### 轮动时序五阶段

```
Day -3（蓄力期）:
  板块连续缩量企稳3天+
  量能萎缩至50日均量以下
  股价横盘或微跌
  无人关注

Day -2（试盘期）:
  龙头个股开始温和放量（但板块整体没动）
  量能恢复至50日均量的60-80%
  单日涨幅+1~3%
  板块讨论度极低

Day -1（确认期）★★★ 这就是买入日
  板块ETF开始温和放量上涨（+0.5~1.5%）
  龙头股+2~5%，但板块内还没出现涨停潮
  量能恢复至正常水平
  板块开始有人讨论但未形成一致性

Day 0（启动/高潮期）⚠️ 已经是尾声
  板块ETF +2~4%
  多只个股涨停
  讨论度暴增
  → 此时追=接盘概率>60%

Day 1（分化/回撤期）:
  龙头可能继续冲高但跟风已跌
  板块整体回调0~-2%
```

### 核心判定规则

```
张飞的任务：在Day -2识别，Day -1确认，Day 0不碰

识别阈值：
  Day -2信号：
    · 板块ETF连续2日量能<50日均量（缩量企稳）
    · 板块内有1只个股逆势温和放量（+1~2%）
    
  Day -1确认：
    · 板块ETF开始温和放量（量比>1.2且<2.0）
    · 板块ETF涨幅+0.5~1.5%（非高潮）
    · 板块内多只个股放量（非单一炒作）
    · 一致性指数<50%（还没人讨论）
    
  Day 0禁止：
    · 板块涨幅>2%
    · 涨停家数≥2
    · 一致性指数>70%
```

## 二、每日/周末强制检查清单

### 收盘后强制检查

```
□ 全市场ETF涨幅榜 → 前5名是谁？
  涨幅>2%的 → 可能已到Day 0 → 标记⚠️
  涨幅0.5-1.5%的 → 可能是Day -1 → 标记🟢

□ 全市场ETF量能检查 → 谁在缩量企稳？
  连续3日量能<50日均量的 → 标记蓄力中

□ 涨停板复盘 → 哪个板块出现首家涨停？
  新板块首家涨停 → 可能的点火信号

□ 龙头个股复盘
  板块内谁放量不涨（建仓信号）
  谁放量上涨（启动信号）
```

### 周末强制检查

```
□ 过去5日板块轮动复盘
  本周谁蓄力了（连续缩量横盘）
  本周谁高潮了（放量暴涨后回落）
  下周可能轮动到谁（蓄力中+有催化）

□ 下周事件日历
  政策会议/数据发布/展会/财报
  谁有确定性催化
```

## 三、与全系统联动

### 张飞检测结果 → 自动同步

```
张飞判定为Day -1（确认买入日）：
  → 🟢 通知刘彻：该板块列为尾盘埋伏候选（优先级最高）
  → 🟢 通知汉武帝：明日开盘后可执行
  → 🟢 通知刘备：检查政策和舆情
  → 🟢 通知秦始皇：检查仓位是否容纳
  → 🟢 通知诸葛亮：筛选板块内最佳候选

张飞判定为Day 0（已启动/高潮）：
  → 🔴 通知刘彻：禁止该板块新开仓
  → 🔴 通知汉武帝：已有仓位只卖不买
  → 🔴 通知刘备：该板块舆情一致性过高
  → 🟡 通知秦始皇：已有仓位上调止盈

张飞判定为Day -2（试盘）：
  → 🟡 通知刘彻：该板块放入观察池
  → 🟡 通知诸葛亮：筛选候选但不买入
```
