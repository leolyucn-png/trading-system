# 🗡️ 张飞模型 V2.0 — 反人性主力博弈引擎（量价分层版）

> 版本：v2.0 | 建立：2026-07-25 | 废弃旧V1.0一刀切规则
> 核心逻辑：【20日价格分位前置判断 + 量价四象限】→ 量化情绪辅助验证 → 分层判定
> 定位：数据加工层，不输出买卖指令，只输出【风险等级+情绪标签+量价分类】，供刘彻/秦始皇/龙虾消费

## 一、底层三大公理（分层修订，不可变更）

| 公理 | 原版（废弃） | 修订版 |
|:----|:-----------|:------|
| **公理1：一致性=死亡** | 全市场看多=要跌（一刀切） | 仅在**高位（70-100%）+放量滞涨**时生效，中性位置的一致性看市场人气 |
| **公理2：主力反人性** | 散户恐慌=买点（无视位置） | 仅在**低位（0-30%）+缩量企稳+任意一项情绪指标**支持时生效，高位恐慌不抄底 |
| **公理3：出货路径** | 放量=可能出货（误伤连板） | 高位放量滞涨才标记出货；连板票（近3日≥2板）豁免此判定，走中段规则 |

## 二、核心判定框架

### 2.1 20日价格分位（前置判断）

```
计算方法：当前收盘价在近20日最高最低区间内的百分位

低位区    0%  ────────────────────  30%    ← 关注机会（下行风险有限）
中段区   30%  ────────────────────  70%    ← 正常交易区（不做风控拦截）
高位区   70%  ──────────────────── 100%    ← 关注风险（上行收益有限）
```

**分位计算（ETF与个股通用）：**
```
分位 = (当前价 - 20日最低) / (20日最高 - 20日最低) × 100
```

### 2.2 量价四象限（核心引擎）

#### 量能基准
- 基准量 = 近20日日均成交额
- **放量**：当日成交额 ≥ 基准量 × 1.5
- **缩量**：当日成交额 ≤ 基准量 × 0.7
- **平量**：介于两者之间

#### 四象限定义

| 象限 | 量 | 价格（当日涨跌） | 低位(0-30%) | 中段(30-70%) | 高位(70-100%) |
|:----|:--:|:---------------:|:-----------|:------------|:-------------|
| **Ⅰ放量上涨** | ≥1.5x | >0% | 🟢 **强势启动信号** 关注机会 | 🟢 正常走强，趋势延续 | 🟡 可能加速赶顶，结合情绪看 |
| **Ⅱ放量滞涨** | ≥1.5x | -1% ~ +1% | 🟡 有资金进场但价格不动，观察 | 🟡 多空分歧，观望 | 🔴 **出货预警** 高风险 |
| **Ⅲ缩量上涨** | ≤0.7x | >0% | 🟢 抛压轻，持筹稳定 | 🟢 健康上涨，缩量创新高可持有 | 🟡 上涨乏力苗头，警惕 |
| **Ⅳ缩量下跌** | ≤0.7x | <0% | 🟡 缩量阴跌，可能是底部区域 | 🔴 弱势，可能继续回调 | 🔴 **趋势转弱** 减仓信号 |
| **放量大跌** | ≥1.5x | <-2% | 🔴 抄底谨慎，等企稳信号 | 🔴 恐慌性下跌，回避 | 🔴 踩踏出逃，立即回避 |

> **放量大跌** 是放量上涨的对立面，在四象限中没有单独占位，但它是实操中最危险的信号之一，因此单独列出。

### 2.3 连板豁免规则（防止错杀主线连板）

```
条件：近3个交易日内出现≥2次涨停（涨幅≥9.8%）
处理：强制走【中段规则】，不触发任何高位预警/低位机会

原因：连板票的分位计算天然在高位，量通常1.5x+，
      按正常规则会被标记"高位放量上涨→加速赶顶"，
      但连板本身就是这种量价形态，规则会反复误报。
      连板票的唯一卖点是【断板+放量】，不是分位高低。
```

## 三、五大情绪指标（辅助验证，不自作主张）

所有情绪指标**只做加减分**，不做独立的买卖判断。最终判定依赖位置+量价。

| # | 指标 | 数据源 | 判定逻辑 | 权重 |
|:-:|:----|:------|:--------|:----:|
| 1 | **散户热度** | 东财股吧帖子量（日环比） | 帖子量>日均3倍=过热(-2), <0.5倍=恐慌(+1) | ±2 |
| 2 | **龙虎榜散户席位** | 龙虎榜买入/卖出结构 | 散户席位占比>70%=过热(-2), <30%=机构主导(+1) | ±2 |
| 3 | **融资余额变化** | 沪深融资余额(日环比) | 融资加速(>3日连增)=-1, 融资骤降(单日>2%)=+1 | ±1 |
| 4 | **板块涨停密度** | 板块内涨停家数/成分股总数 | >10%=过热(-1), <2%=冷清(0) | ±1 |
| 5 | **量比异常** | 个股量比（相对5日均量） | 量比>5且涨幅<1%=异常放量(-1) | ±1 |

**情绪总分范围：-7 ~ +6**
- 总分 ≤ -3：市场情绪过热，警惕反转
- 总分 ≥ +3：市场情绪恐慌或低迷，可能存在机会
- 中间值：正常状态，不做情绪干预

## 四、分层判定逻辑（最终输出）

### 4.1 高位区（70-100%）

```
┌─ 量价判定 ───────────────┐
│ 放量滞涨？                │
│ 是 → 检查情绪            │
│    ├ 任意1项情绪支持 → 🔴 风险预警（拦截买入/考虑减仓）
│    └ 无情绪支持 → 🟡 观察（不拦截）
│                           │
│ 放量上涨？                │
│ ├ 连板豁免生效 → 🟡 中段规则（不预警）
│ └ 未连板+情绪过热 → 🔴 加速赶顶预警
│                           │
│ 其他 → 🟢 正常（不预警）  │
└───────────────────────────┘
```

### 4.2 低位区（0-30%）

```
┌─ 量价判定 ───────────────┐
│ 缩量企稳/放量启动？       │
│ 是 → 检查情绪            │
│    ├ 任意1项情绪支持 → 🟢 机会提示（关注候选池）
│    └ 无情绪支持 → 🟡 观察（不入池）
│                           │
│ 放量大跌？                │
│ → 🔴 回避（等缩量企稳信号）│
│                           │
│ 其他 → 🟡 观望            │
└───────────────────────────┘
```

### 4.3 中段区（30-70%）

```
→ 只统计人气打分，不做风控拦截
→ 连板票无论分位多少，强制走此规则
→ 输出：人气温度（冷/常温/热）供刘彻参考
```

## 六、配置文件区（所有可调参数）

```python
# === 分位参数 ===
POSITION_LOW = 30       # 低位上限(%)
POSITION_HIGH = 70      # 高位下限(%)
PERIOD_DAY = 20         # 分位计算周期(日)

# === 量价参数 ===
VOLUME_HIGH = 1.5       # 放量倍数
VOLUME_LOW = 0.7        # 缩量倍数
VOLUME_PERIOD = 20      # 均量计算周期(日)
PRICE_FLAT_MAX = 1.0    # 滞涨判定上限(%)
PRICE_FLAT_MIN = -1.0   # 滞涨判定下限(%)

# === 连板豁免 ===
LIMIT_UP_DAYS = 3       # 检测窗口(日)
LIMIT_UP_COUNT = 2      # 涨停次数阈值

RETAIL_THRESHOLD = 70   # 散户席位占比阈值(%)
MARGIN_SURGE_DAYS = 3   # 融资连续增长天数
MARGIN_DROP = 2.0       # 融资骤降阈值(%)
ZDT_DENSE = 10          # 涨停密度阈值(%)
VOL_RATIO_ABNORMAL = 5  # 量比异常阈值
```
