## 特性库使用规则

1. **第一梯队** → 已固化或训练中，系统默认遵守
2. **第二梯队** → 猜想待验，升级为交易信号需走完旭光签名程序（定义量化→预注册→回测→三档判决）

4. **保质期原则**：任何A股规律都有保质期——回测必须逐年看，不看总均值
