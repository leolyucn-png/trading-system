## 一、顶层强制规则（不可修改）

### 规则1：一票否决优先
所有选股必须先通过一票否决项过滤，满足任意一项直接剔除，不参与后续打分。

### 规则2：量化门槛
```
总分100分：
  ≥80分 → 🟢 活跃池（上限5只，宁空勿滥）
  ≥70分 → 🟡 观察池（无上限）
  <70分 → ❌ 剔除
```

### 规则3：风控最高优先级
```
风控规则 > 技术信号 > 资金验证 > 事件催化
触发止损止盈 → 无条件执行，禁止主观格局
```

### 规则4：全程量化
禁止主观判断，所有结论附带原始计算数据，无数据支撑直接作废。

## 三、四维量化打分体系（总分100分，阈值固化）

### 维度1：宏观环境（20分）

| 子项 | 分值 | 判定标准 |
|:----|:---:|:--------|
| 大盘趋势 | 8分 | 标普500周线MA20上方+4分，月线MA60上方+4分 |
| VIX风险 | 7分 | VIX≤15→7分, 15-20→5分, 20-25→3分, 25-30→1分, >30→**本维度0分** |
| 板块资金 | 5分 | 所属板块近5日资金净流入为正→5分，否则0分 |

### 维度2：技术信号（35分）

| 子项 | 分值 | 判定标准 |
|:----|:---:|:--------|
| 均线突破 | 10分 | 股价在20日均线上方+4分，50日均线上方+3分，200日均线上方+3分 |
| 量能配合 | 8分 | 近5日均量>20日均量1.5倍→8分，>1.2倍→5分，否则0分 |
| RSI健康 | 7分 | RSI(14)在40-60→7分，30-40或60-70→4分，<30或>70→1分 |
| 箱体突破 | 6分 | 突破20日高点→6分，接近高点→3分，否则0分 |
| 相对强度 | 4分 | 近20日涨幅跑赢SPY→4分，否则0分 |

### 维度3：资金验证（25分）

| 子项 | 分值 | 判定标准 |
|:----|:---:|:--------|
| 机构资金 | 8分 | 机构持仓环比提升→8分，维持→4分，下降→0分 |
| 板块共振 | 7分 | 所属板块近5日涨幅前10→7分，前20→4分，否则0分 |
| 期权联动 | 6分 | 看涨/看跌比>1.5→6分，>1.0→3分，<1.0→0分 |
| 大单成交 | 4分 | 近3日出现异常大单成交→4分，否则0分 |

### 维度4：事件催化（20分）

| 子项 | 分值 | 判定标准 |
|:----|:---:|:--------|
| 明确催化 | 10分 | 产品/政策/财报等可验证催化→10分，传闻级→5分，无→0分 |
| 预期差 | 6分 | 分析师上调评级/目标价→6分，维持→3分，下调→0分 |
| 边际利好 | 4分 | 行业边际改善/竞争对手利空→4分，否则0分 |

## 四、候选池分层与进出规则

### 🟢 活跃池（上限5只）
```
进入条件：四维总分≥80分 + 全部一票否决通过
持有周期：10-15个交易日
退出条件：触发止损/止盈/到期/利空 → 当日调出
```

### 🟡 观察池
```
进入条件：四维总分≥70分 + 全部一票否决通过
升级条件：跟踪3日，总分升至80分+ → 升入活跃池
退出条件：跟踪满10日未升级 → 自动淘汰
```

### 🔴 预警池（实时监控）
```
持仓股触发以下任一 → 移入预警池，标记操作建议：
  □ 当日跌幅＞10%
  □ 板块暴跌＞3%
  □ 突发利空消息
```

## 五、风控体系（强制优先级最高）

### 5.1 仓位控制

| VIX区间 | 总仓位上限 | 单票上限 | 单行业上限 |
|:-------:|:---------:|:-------:|:---------:|
| ≤15 | 80% | 15% | 30% |
| 15-20 | 60% | 12% | 25% |
| 20-25 | 40% | 10% | 20% |
| 25-30 | 20% | 5% | 10% |
| >30 | **空仓** | 0% | 0% |

### 5.2 止损止盈

```
硬止损：-7% → 无条件执行，不格局
时间止损：持有满15个交易日未达止盈 → 清仓
移动止盈：从最高点回撤50%的盈利 → 离场
```

### 5.3 特殊风控

```
单日跌幅＞10% → 次日减半仓
大盘单日暴跌＞3% → 总仓位压至30%以下
```

## 六、每日运行流程

### 盘前（开盘前1小时）
```
□ VIX数值检查 → 确定总仓位上限
□ 大盘趋势判定 → 标普500周线/月线位置
□ 今日财报日历 → 检查持仓及候选是否有财报发布
```

### 盘中（每30分钟）
```
□ 持仓风控检查 → 是否触发止损/止盈/特殊风控
□ 异动扫描 → 量比异常、板块异动
```

### 收盘后
```
□ 初筛 → 一票否决过滤全市场
□ 四维打分 → 输出TOP10候选
□ 池子更新 → 活跃池/观察池进出
□ 持仓风控 → 止损止盈临近标的提醒
```

### 每周五
```
□ 周度复盘 → 胜率/盈亏比/最大回撤
□ 池子清理 → 过期候选淘汰
□ 迭代阈值 → 回测数据微调参数
```

## 八、防违规自检

### 严重违规（直接作废，记录错误台账）
```
□ 跳过一票否决直接打分
□ 无数据支撑的打分/结论
□ 使用事后数据解释当日走势
□ 跳过风控规则
□ 输出内容被截断/省略
```

### 一般违规（自动修正）
```
□ 使用主观判断代替量化数据
□ 未按固定模板输出
□ 结论缺少原始数据支撑
```
