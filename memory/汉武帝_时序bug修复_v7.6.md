# 🦁 汉武帝 · 时序bug修复补丁 v7.6

> 问题：所有推荐滞后1天，涨停潮日买入→次日暴跌
> 修复：以"信号出现日"为Day 0，买入提前到Day -1

---

## 一、问题定义

### 错误模式（贯穿所有系统）

```
Day -1：个股出现异动（放量不涨/建仓信号）→ 没人发现
Day 0：涨停潮/板块集体爆发 → 系统发现 "机会"→ 尾盘买入
Day 1：板块分化/暴跌 → 持仓亏损 → 止损

错误本质：把"高潮"当成了"启动"。
涨停潮日买入=给前面埋伏的人接盘。
```

### 三个案例验证

| 票 | Day -1(该买) | Day 0(实际买) | 结果 |
|:--|:-----------|:------------|:----|
| 楚江新材 | 6/19五放量+2.1% | 6/22一+4.6%买入 | 6/23二-8.28%亏 |
| 国机精工 | 6/19五放量+3.2% | 6/22一+7.6%买入 | 6/23二-6.38%亏 |
| 宗申动力 | 6/19五异动 | 6/22一+1.4%买入 | 6/23二-6.58%亏 |

**结论：Day 0的信号=给你看的陷阱。真机会在Day -1。**

## 二、系统级修复

### 修复1：信号分类（废除"看到涨再买"）

```
旧逻辑（已废除）：
  涨停潮 → 发现机会 → 尾盘买入 → 次日暴跌

新逻辑（v7.6强制）：
  放量不涨 → 建仓信号 → 尾盘买入 → 次日拉升
  涨停潮 → 高潮信号 → 不买，找卖点

核心规则：
  ✅ 只买：放量不涨(量比>3+涨幅<2%)、缩量回调、抗跌企稳
  ❌ 禁止买：涨停潮、板块涨幅>3%、连涨≥3天
```

### 修复2：买入信号必须提前1天

```
所有推荐必须过"超前1天检查"：

如果今天(14:25)看到一个买入信号 →
  反问：这个信号今天才出来吗？
    → 如果是今天第一次出现 → 可买（真启动）
    → 如果已经是第2天出现 → 不买（等回调）

信号时效性检查：
  第1天出现：放量不涨/异动 → ✅ 可买
  第2天出现：涨了跟风 → ❌ 不买，等回调
  第3天出现：涨停潮 → ❌ 不买，找卖点
```

### 修复3：加入"高潮识别器"

```
任何板块/个股满足以下条件 → 自动判定为"高潮"
  □ 板块涨幅>3%
  □ 板块内涨停≥3只
  □ 舆情热度突然飙升
  □ 各大群都在讨论

高潮日规则：
  → 禁止买入：当天不推任何该板块的票
  → 强制倒查：推该板块当天已经涨了多少？
    如果已涨>3% → 这条推荐作废
```

### 修复4：预判型买入替代反应型买入

```
预判信号清单（代替涨停潮追高）：
  □ 昨天板块跌-2~-5%，今天缩量企稳 → 明天可能反弹
  □ 个股昨天放量不涨，今天缩量微跌 → 洗盘完成
  □ 大盘跌它不跌（抗跌）→ 有资金护盘
  □ 大盘涨它不动（滞涨）→ 在吸筹

这些信号出现 → 明天大概率涨 → 今天尾盘埋伏
```

## 三、各系统修复

### 🦁 汉武帝修复
```
旧：今天涨→今天买→明天卖
新：今天异动(放量不涨)→今天买→明天涨→卖
    今天涨停潮→今天不买，看谁有异动
    今天滞涨→今天埋伏，等明天轮动

选股条件修改：
  ❌ 删除：涨幅靠前的票（已涨=晚了）
  ✅ 增加：放量不涨/缩量回调/抗跌异动
```

### 🐉 刘彻修复
```
刘彻的策略A本来就是"预判埋伏"，
问题在于执行时还是选了当天涨的票。

强化规则：
  ✅ 埋伏标的当天涨幅必须<2%（没启动的）
  ❌ 当天涨幅>3%的票剔除埋伏候选
```

### 🏯 诸葛亮修复
```
诸葛亮找的是"独立走强DNA"，
但识别出候选后必须检查时间点。

新增规则：
  候选票须在"启动初期"（60日涨幅<30%）
  已涨>50%的候选→降级到观察池
  已涨>100%的候选→永久归档
```

## 五、一句话核心

> **买到涨=赚，等到涨了才买=亏。所有赚钱的信号都在"还没涨"的时候。涨停潮日不是机会日，是陷阱日。**
