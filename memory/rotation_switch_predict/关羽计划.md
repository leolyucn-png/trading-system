## 三、高低切换量化打分体系（总分0-100）

### 维度1：高位赛道衰退分（40分）

| 扣分项 | 幅度 | 扣分 |
|:------|:----|:----:|
| 近3日涨幅TOP20板块今日资金拐头流出 | 每个板块 | -5分 |
| 板块换手率>15%（过热） | 每个 | -3分 |
| 板块获利盘比例>80% | 每个 | -3分 |
| 板块成交额占比>20% | 每个 | -5分 |
| 龙头股放量滞涨/天地板 | 出现 | -10分 |

**得分 = 40 - 累计扣分（最低0分）**

### 维度2：低位板块回流分（35分）

| 加分项 | 幅度 | 加分 |
|:------|:----|:----:|
| 近1个月超跌>15%后企稳 | 每个板块 | +5分 |
| 低位横盘>5日+今日放量 | 每个板块 | +5分 |
| 日内逆势净流入（大盘跌它吸金） | 每个板块 | +5分 |
| 连续3日小额资金净流入（蓄力） | 每个板块 | +8分 |
| 板块内有涨停股出现 | 每只 | +3分 |

**得分 = 累计加分（上限35分）**

### 维度3：资金跷跷板分（15分）

```
测量：高位赛道流出总额 vs 低位板块流入总额
公式：匹配度 = 1 - |流出 - 流入| / max(流出, 流入)

匹配度>80% → 15分（典型高低切，资金一一对应搬家）
匹配度50-80% → 8分（部分分流，非全盘切换）
匹配度<50% → 2分（非高低切，可能是独立事件）
```

### 维度4：大盘环境适配分（10分）

```
大盘状态：
  🟢 强势普涨（上证>+1%且个股涨多跌少）→ 切换信号弱化 → 2分
  🟡 震荡分化（上证-0.5%~+0.5%）→ 中性 → 5分
  🔴 弱势下跌（上证<-0.5%或创业板<-1%）→ 切换信号强化 → 10分
  💀 系统性风险（上证<-2%）→ 切换无意义，全部减仓 → 2分
```

### 总分与档位

```
总分 = 维度1 + 维度2 + 维度3 + 维度4

≥70分 → 🔴 强高低切换
  明确主线切换，规避高位赛道，布局低位轮动方向
  操作：禁止新开高位仓位，优先布局低位板块

45~69分 → 🟡 弱轮动分化
  结构性小幅分流，资金试探性转移
  操作：谨慎追高位，小仓位试错低位

<45分 → 🟢 无明显切换
  原有热点延续，资金仍集中在主线
  操作：维持原有主线操作不动
```

## 🆕 V1.1升级内容（2026-06-30 11:10）

### 升级1：资金统计粒度下放到二级概念

#### 问题
```
原系统仅统计一级行业（如"军工"）整体资金流
但机器人概念的资金流会被军工大板块稀释
导致细分方向的资金异动被完全掩盖
```

#### 新增规则
```
同步读取全市场概念板块分时资金流（不止一级行业）

细分概念独立统计：
  机器人、人形零部件、减速器、低空经济、军工电子
  光伏组件、逆变器、光伏设备、分布式光伏
  创新药、CXO、中药、化学制药
  半导体设备、封测、材料、设计

每个细分独立计算：
  □ 日内资金净流入/流出
  □ 近3日累计净流入/流出
  □ 细分跷跷板系数（不被所属大板块稀释）
```

### 升级2：新增短周期资金异动判定（15分钟分时维度）

#### 问题
```
原系统仅用30分钟和日线维度打分
30分钟维度对于早盘异动反应太慢
日线维度到了收盘才能确认
结果：09:43确认的机器人方向，系统要到10:30才能打分
```

#### 新增15分钟分时加分项
```
① 早盘09:35-09:50首个15分钟连续净流入 → +5分
② 集合竞价阶段细分概念逆势净流入（大盘跌它吸金）→ 直接标记【启动前置信号】
③ 开盘30分钟内板块涨幅<2%但资金大幅净流入 → 启动信号优先于价格信号

意义：不等价格涨了3%+才知道资金来了
       在09:43就能识别，10:00前完成判定
```

### 升级3：优化主线衰退判定 — 渐进式兑现识别

#### 问题
```
原系统仅基于单日大额流出判定主线衰退
但真正的资金撤退往往是渐进的：
  第1天：小幅减仓（散户没感觉）
  第2天：继续减仓（半信半疑）
  第3天：加速流出（确认）
等到单日大额流出出现时 → 已经晚了
```

#### 新增边际衰减指标
```
主线板块连续3个交易日净流入环比收窄 → 标记【资金兑现中】
主线高位个股持续净流出（3日累计）→ 标记【个股撤退】
板块ETF份额连续下降 → 标记【机构撤退】

以上任一触发 → 自动启动全市场低位细分资金扫描
不等单日大额流出信号出现
```

### 升级4：高低切双信号联动刘备V2.1

#### 联动规则
```
关羽资金信号 + 刘备V2.1舆情信号 = 双信号确认

低位细分资金持续流入 + 刘备判定题材缓慢升温
  → 双信号确认 → 输出【🔥 强切换预判】
  → 直接推动刘彻策略A从该细分选题

只有资金流入但没有舆情升温：
  → 可能是昙花一现，标记【⚠️ 伪切换-缺舆情】

只有舆情升温但没有资金流入：
  → 可能是吹票，标记【⚠️ 伪题材-缺资金】
```

## 六、防滞后纠错机制

### 1. 区分真伪切换

```
✅ 真切换：连续2个时段（如10:00+11:30）资金持续净流入
❌ 伪切换：单一时段脉冲流入后流出（一日游套利）

规则：必须连续2个以上时段确认 → 才判定有效异动
```

### 2. 标记伪切换信号

```
伪切换特征：
  - 单日板块涨幅>5%但资金净流入<1亿
  - 板块内涨停股<2只（龙头效应弱）
  - 北向资金逆势流出（聪明钱不认可）
  - 板块ETF溢价率突降（申购套利盘）

标记为：⚠️ 伪切换（一日游行情的概率>60%）
```

### 3. 收盘后自检

```
每次预判后收盘对照真实行情：
  □ 预判的方向对了/错了？
  □ 切换力度（强/弱/无）对了/错了？
  □ 错误原因：数据缺失 / 权重偏差 / 信号误读
  □ 更新权重系数（迭代打分体系）
```

### 4. 第一判定原则

```
❌ 禁止只看涨跌幅判断热点
✅ 必须以资金流向作为第一判定依据
   涨跌幅=结果，资金流向=原因，北向=验证
```
