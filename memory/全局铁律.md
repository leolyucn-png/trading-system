## 一、技能使用强制规则

1. 输出结论前，必须优先调用已安装技能获取真实数据
2. 严禁凭空编造技能输出、伪造返回值、虚构数据源
3. 技能无模型专属限制，所有模型交叉共享
4. 技能调用失败/无返回 → 标注「技能调用失败，无法验证」→ 禁止用生成内容替代

## 二、输出有据强制规则

1. 所有判断/推荐/指令必须附带明确依据（规则条目/技能数据/历史验证）
2. 无法验证的内容 → 标注「待验证」「不确定」→ 不得输出确定性结论
3. 禁止脱离已安装技能与固化规则自由发散

## 三、记忆强制加载规则

1. 每次启动必须加载：
   □ 全局永久记忆（MEMORY.md/铁律/模型定位）
   □ 近2个交易日经验日志
2. 决策输出前必须经过记忆校验
3. 不得违背已固化的铁律与已验证历史经验

## 四、全量记录归档规则

1. 每日操作/信号/复盘/优化 → 写入当日经验日志
2. 通用铁律 → 同步更新全局永久记忆
3. 技能失败/异常/冲突 → 单独归档 → 纳入迭代清单
