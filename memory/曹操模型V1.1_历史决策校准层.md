## 一、为什么要有曹操

```
现有11模型 = 专家系统（规则驱动）
所有逻辑 = 人手写
所有权重 = 人拍板

问题：写了一年规则，从来没回头问过——
  → 我写的这条规则，历史上真的管用吗？
  → 关羽给70分的时候，我们真的赚到钱了吗？
  → 小乔说A级买点的时候，盈利率到底是多少？

曹操的任务：回答这些问题。
```

### 与赵云的分工

| | 赵云（复盘归因） | 曹操（决策校准） |
|:--|:--|:--|
| **方向** | 事后分析 ← 过去 | 事前校准 → 未来 |
| **问的问题** | 这笔亏损是谁的错？ | 这个信号历史上管用吗？ |
| **输出** | 归因报告 | 置信度修正因子 |
| **运行** | 收盘后15:45 | 每次决策前 |
| **用户** | 人（复盘看） | 机器（喂给其他模型） |

## 二、数据输入层（四类）

### L1 · 市场结果数据
```
全A股日线OHLCV → 用于计算「这笔交易到底赚了多少」
         → 用于计算同期大盘/板块收益（基准对比）
资金流数据 → 用于验证关羽的方向判断
板块涨跌幅 → 用于验证秦始皇/刘彻的板块轮动判断
20日均线方向 + 成交量水位 → 市场状态分类
```

### L2 · 你的决策数据（核心资产 + V1.1扩增反事实样本）
```
✅ 已执行交易（V1.0就有）：
  - 买什么、几点买、什么价买
  - 关羽分、板块、大盘状态
  - 买入后T+1/3/5/10天收益

🆕 反事实样本（V1.1新增）：
  - 信号触发但你没买（关羽≥50分，系统推荐但未执行）
  - 卖飞的票（卖了后T+5涨幅）
  - 错过的板块（关羽报警的板块你没建仓，后来涨了多少）
  
  ⚠️ V1.1阶段反事实数据不全 → 置信度自动打7折
```

### L3 · 模型输出数据
```
关羽：每次运行的分值+方向+板块（09:35/10:00/11:30/13:35/14:25）
刘备：舆情验证的真/假/不确定标记
张飞：一致性预警 or not
小乔：A/B/C/D买点评级
大乔：卖出信号 or not
汉武帝：GATE 0/1/2/3 各项打分

🆕 模型组合标记（V1.1新增）：
  关羽分 + 刘备验证状态 + 张飞预警状态 → 三位一体组合ID
  例：关羽70分×刘备通过×张飞无预警 → 组合ID A3
  例：关羽70分×刘备未验证×张飞预警 → 组合ID X7
```

### L4 · 反思数据
```
赵云归因报告：每笔亏损=谁的错（追高/踏空/卖飞/止损）
经验教训库：每次新增的模式和规则
复盘日志：每天的「做对了什么/做错了什么」
```

## 三、V1.1 五大核心升级

### 🔴 升级1：基准对比（Benchmark）—— V1.0最致命的遗漏

```
❌ V1.0旧逻辑：信号收益 = 买入后涨幅
   问题：信号+1.2%，同期大盘+1.5% → 表面赚钱实则负alpha

✅ V1.1新逻辑：
   超额收益 = 信号收益 - max(同期大盘收益, 同期板块收益)
   
   判定规则：
   - 超额收益 > 0 → 信号有真实alpha
   - 超额收益 ≈ 0 → 信号靠大盘带的，没有独立预测能力
   - 超额收益 < 0 → 信号是负alpha，该降权甚至禁用
```

### 🔴 升级2：市场状态分层 —— 牛熊分离

```
同一个信号，牛市和熊市里的胜率是两个世界。

V1.1强制五状态分类：

┌──────────┬──────────────────┬────────────┐
│ 状态     │ 判定条件          │ 识别标志    │
├──────────┼──────────────────┼────────────┤
│ 🟢 牛市  │ 大盘>20MA + 量能>均值 │ 普涨氛围   │
│ 🟡 牛震  │ 大盘>20MA + 量能<均值 │ 缩量整理   │
│ 🔵 熊反  │ 大盘<20MA + 量能>均值 │ 超跌反弹   │
│ 🔴 熊市  │ 大盘<20MA + 量能<均值 │ 阴跌不止   │
│ ⚪ 震荡  │ 大盘在20MA±2%内      │ 方向不明   │
└──────────┴──────────────────┴────────────┘

每个信号的历史统计，必须按市场状态分开算：
  → 牛市里关羽70分胜率75%
  → 熊市里关羽70分胜率40%
  → 结论：熊市时关羽70分不可信

⚠️ 当前市场状态由秦始皇在GATE 0阶段判定
```

### 🔴 升级3：时间衰减权重

```
市场在变，规则在迭代。2023年行情不能稀释2026年信号。

衰减规则：
  最近1个月    ：权重 2.0  🔥
  1-3个月前    ：权重 1.5
  3-6个月前    ：权重 1.0
  6-12个月前   ：权重 0.5
  12个月以上   ：权重 0.2（仅作参考，不参与置信度修正）

示例：
  关羽70分×军工 历史10次触发
  其中2次在最近1月（权重2.0）、3次在1-3月（权重1.5）、5次在半年前（权重0.5）
  → 加权胜率 ≠ 简单平均，近期样本权重主导结论
```

### 🔴 升级4：反事实样本 —— 打破幸存者偏差

```
❌ V1.0只统计「你买了的票」
   问题：你买了的68%赚钱 ≠ 你系统选出来的68%赚钱
        你可能拒绝了80%都涨了的信号

✅ V1.1必须追踪三类反事实：

类型A：信号→未执行
  关羽给了信号，系统推荐了，但最终没买
  追踪：如果买了，T+1/T+5收益率多少？

类型B：已卖→后来涨了
  大乔或人为卖出后，继续追踪T+5/T+10
  用于衡量卖飞的代价

类型C：板块→未建仓
  关羽报警了某个板块但没选个股
  追踪：该板块接下来T+3/T+5的涨幅

⚠️ V1.1现实约束：
  反事实数据目前不全 → 所有输出置信度自动×0.7
  等反事实样本积累≥50次后 → 取消折扣
```

### 🔴 升级5：样本量置信区间

```
❌ V1.0写法：胜率68%
   问题：如果是5个样本算出来的68%，毫无意义

✅ V1.1强制分档：

┌────────────┬────────────────────────────────┐
│ 样本量     │ 处理方式                        │
├────────────┼────────────────────────────────┤
│ < 10次     │ 不参与置信度修正，只标注参考值    │
│ 10-20次    │ 给出置信区间（如68%±15%）        │
│ 20-30次    │ 可参与修正，但权重打7折          │
│ > 30次     │ 正常参与修正                    │
└────────────┴────────────────────────────────┘

铁律：样本量<20次的统计结果，不能直接用来否定/肯定任何模型信号。
```

## 四、核心引擎（三大引擎）

### 引擎1：信号→超额收益映射

```
输入：关羽分=70, 板块=军工, 时间=14:25, 市场状态=牛震
查询：同市场状态下历史所有类似场景
输出：
  - 同类场景出现次数：N=23（>30，置信度充分）
  - 信号平均收益：+1.2%
  - 同期大盘收益：+0.8%
  - 同期板块收益：+1.1%
  - 超额收益：+0.1%（≈0，信号基本无独立alpha）
  - 正收益概率：68%
  - 加权正收益概率（时间衰减后）：62%（近期样本表现更差）
  - 判定：⚠️ 弱有效信号——收益主要靠市场带的，近期在衰减
```

### 引擎2：决策→错误映射

```
输入：当前时间=14:20, 市场状态=牛市, 已跑模型=关羽+刘备
查询：历史所有「14:20时你在牛市里做了什么」
输出：
  - 14:20-14:30间你冲动买入 N 次
  - 冲动买入的平均超额收益：-1.8%（跑输大盘）
  - 尾盘执行的平均超额收益：+0.5%
  - 判定：⚠️ 高风险窗口——在牛市里你更急，反而更容易买早
```

### 引擎3：模型组合→联合校准（V1.1新增）

```
关羽70分 → 胜率68%
关羽70分 + 刘备验证通过 → 胜率78%（↑10%）
关羽70分 + 刘备验证失败 → 胜率42%（↓26%）
关羽70分 + 张飞预警 → 胜率31%（↓37%）
关羽70分 + 刘备通过 + 张飞无预警 → 胜率82%（最高置信度）

结论：单独看关羽不够，组合信号才有真价值。
```

## 六、在系统中的位置

```
赵云（复盘归因）──────────────┐
                              ↓
                        ⚔️ 曹操 V1.1
                     （历史决策校准层）
                              │
                    输出置信度修正因子
                              │
                  ┌───────────┴───────────┐
                  ↓           ↓           ↓
              关羽/刘彻   小乔/大乔   汉武帝/诸葛亮
              （接收修正）（接收修正）（接收修正）
                              │
                              ↓
                        龙虾（执行）
```

- 曹操不参与买卖决策
- 曹操不替代任何现有模型
- 曹操只在其他模型输出后，追加一个置信度修正卡
- 模型可以选择采纳或忽略（但忽略需注明理由）

## 七、铁律

```
1. 只输出置信度修正，不替代任何模型的买卖建议
2. 所有统计必须附带「基准对比」——超额收益才算真alpha
3. 样本量<20的结果 → 不能参与实际修正，只标参考值
4. 样本量<10的结果 → 不在输出卡中展示，归档到后台
5. 反事实数据不足 → 置信度自动×0.7，样本够了取消
6. 各市场状态下的统计必须独立计算，禁止混算
7. 时间衰减权重每月自动更新
8. 曹操自己每个月接受赵云回溯验证 —— 验证曹操的修正到底有没有用
```

## 八、技术实现

### V1.1方案：规则引擎 + 基准对比

```
核心SQL逻辑伪代码：

SELECT 
  关羽分档,
  板块,
  市场状态,
  COUNT(*) as 样本量,
  AVG(信号收益 - 同期大盘收益) as 超额收益,
  SUM(CASE WHEN 信号收益 > 同期大盘收益 THEN 1 ELSE 0 END) / COUNT(*) as 胜率,
  -- 时间衰减加权
  SUM(CASE 
    WHEN 距今<30天 THEN 2.0 
    WHEN 距今<90天 THEN 1.5 
    WHEN 距今<180天 THEN 1.0 
    WHEN 距今<365天 THEN 0.5 
    ELSE 0.2 
  END * CASE WHEN 信号收益>同期大盘收益 THEN 1 ELSE 0 END)
  / SUM(时间权重) as 加权胜率
FROM 历史交易记录
WHERE 样本量 >= 10
GROUP BY 关羽分档, 板块, 市场状态
```
