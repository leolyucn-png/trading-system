## 四大能力

### 能力一：抓"未发酵、潜伏期、预期差"题材

| 信号类型 | 来源 | 判断标准 |
|:--------|:----|:--------|
| 政策吹风 | 部委官网/领导讲话 | 标题含"研究""酝酿""拟""征求意见" |
| 征求意见稿 | 国务院/发改委/工信部 | 文件未正式发布，但方向已定 |
| 试点通知 | 地方/部委 | 小范围试点→扩大→政策落地路径 |
| 会议讲话 | 重要会议/论坛 | 领导发言中的"下一步工作""重点推进" |
| 行业前瞻 | 券商/咨询报告 | 机构提前看好的方向，不为人知 |
| 小范围信号 | 雪球/微博/行业论坛 | 讨论量低但质量高 |

**输出标注：**
- 🔥【未发酵】—— 尚未被市场注意到
- 🟡【低关注】—— 有人提但没形成共识
- 💎【潜在爆发】—— 信号强+催化近

### 能力二：抓"资金先行"信号（比新闻早）

| 信号 | 含义 | 置信度 |

| 尾盘抢筹 | 14:50-15:00放量拉升 | 🟡 值得关注 |
| 成交量异常 | 量比>3，涨幅<3%（低位放量） | 🔴 强信号 |
| 北向提前流入 | 板块连续3天北向加仓但股价没涨 | 🔴 强信号 |
| 主力试探性买入 | 超大单净流入>1亿，股价横盘 | 🟡 |
| 龙虎榜提前布局 | 机构席位上榜，非游资助攻 | 🟡 |

**核心逻辑：** 资金会先于新闻。找到"钱去了但新闻还没出"的地方。

### 能力三：抓"财报前瞻"合法信号

| 信号 | 数据源 | 用法 |
|:----|:-------|:----|
| 券商一致预期变化 | 朝阳永续/东方财富 | 上修=利好，下修=利空 |
| 行业高频数据 | 行业协会/统计局 | 销量/价格/开工率趋势 |
| 毛利率前瞻 | 上游原材料价格 | 成本下降→毛利率提升 |
| 业绩上修/下修 | 业绩预告/快报 | 提前预判财报好坏 |
| 库存/排产数据 | 行业网站/公司官网 | 订单饱满→营收增长 |
| 现金流前瞻 | 经营现金流/应收账款 | 现金流向好→盈利质量高 |

**不碰：** 内幕消息、未公开业绩、非公开调研纪要

## 🆕 能力五：大盘预判 — 系统性风险前置识别（2026-06-26 新增）

### 定位

> 个股分析再好，大盘一崩全白费。**大盘预判是五系统的前置Gate：先判大盘，再决定是否启动交易系统。**
> 不是11:00跌完了再分析，是08:30开盘前就给出今天风险等级。

### 核心流程

```
08:30 🦞 龙虾产出大盘预判卡（开盘前）
  ↓ 判断今天风险等级（高/中/低）
  ↓
  如果等级=🔴高 → 秦始皇执行仓位管理
  ↓                    ↓ 不启动刘彻/诸葛亮新推荐
  如果等级=🟡中  → 正常启动五系统，但仓位减半
  ↓
  如果等级=🟢低  → 满血启动五系统
  ↓
09:25 竞价数据 → 修正预判
09:45 第一个15分钟 → 最终确认
```

**规则：今天能不能做，08:30就定了。盘中修正只会降低仓位不会增加。**

### 五阶段预判法

#### 阶段一：隔夜预判（08:30-09:15 — 开盘前）

| 信号 | 数据源 | 判断标准 | 对A股影响 |
|:----|:------|:--------|:---------|
| 美股三大指数 | 纳斯达克/标普/道琼斯 | 涨跌>1% → 传导A股 | 同向影响开盘 |
| 中概股（金龙指数） | 纳斯达克金龙指数 | 比美股更直接反映A股情绪 | 创业板/科技方向 |
| A50期货夜盘 | 新交所富时A50 | 直接预判上证开盘 | +/- 0.5%以内=正常 |
| 离岸人民币 | USD/CNH | 贬值>0.5%=外资流出压力 | 权重股承压 |
| 恒生指数夜盘/早盘 | 恒生指数 | 09:00前已先于A股交易 | 同步方向 |
| 重大政策/消息 | 新闻聚合 | 利空/利好级别判定 | 决定全天基调 |

**输出：** 开盘预判卡（偏高/偏弱/震荡）+ 建议仓位上限

**案例（6/26周五）：** 如果昨晚美股科技大跌+中概股崩+人民币贬值 → 预判今天A股低开-1%~-2% → 开盘前仓位应≤30%

---

#### 阶段二：早盘定调（09:20-10:00 — 开盘30分钟）

| 信号 | 判断标准 | 信号强度 |
|:----|:--------|:-------:|
| **竞价成交量** | 竞价量比昨日同期 >1.5 → 放量恐慌或放量抄底 | 🔴 关键 |
| **上证开盘点位** | 开在关键支撑位上方/下方 | 🟡 参考 |
| **开盘15分钟方向** | 前15分钟是冲高/下探/横盘 → 定全天基调 | 🔴 最准 |
| **创业板 vs 上证50** | 创业板跌幅>上证50的2倍 → 小盘恐慌 | 🔴 风险信号 |
| **领涨板块** | 有没有涨幅>1%的板块 → 无=全面弱势 | 🟡 参考 |
| **跌停家数** | 开盘30分钟跌停>10只 → 恐慌情绪蔓延 | 🔴 关键 |
| **北向资金** | 前30分钟净流出>20亿 → 外资出逃 | 🔴 重要 |

**开盘30分钟经验法则：**
```
09:30-09:45 第一个15分钟：消化隔夜信息，方向不定
09:45-10:00 第二个15分钟：第一波真实方向

如果这两个15分钟都是单边下跌，且没有像样反弹 → 
  今天就是单边下跌日，任何上涨都是反弹不是反转
  仓位必须砍掉50%以上

如果这两个15分钟先跌后拉回 → 
  今天是震荡日/修复日，可以持有等待
```

**案例（6/26周五）：**
```
09:30-09:45：上证低开-0.5%→下探到-1%，游戏板块-5%，通信亚跌 → 恐慌信号
09:45-10:00：创业板到-2.16%，半导体独涨+0.95% → 分化，不是全面恐慌
10:00-11:00：半导体翻绿，创业板到-3.68% → 确认单边下跌

判定：9:45的反弹是假反弹 → 10:00就应该减仓50%+
```

#### 阶段三：盘中趋势判断（10:00-11:30 / 13:00-14:00）

**趋势强度六因子：**

| 因子 | 牛市特征（+1分） | 熊市特征（-1分） | 6/26 11:00实测 |
|:----|:--------------|:--------------|:-------------|
| ① 涨跌家数比 | 涨>跌 | 跌>涨，且差距>2:1 | ❌ 全面普跌，-1分 |
| ② 指数分时均线 | 指数在均线上方 | 指数持续远离均线 | ❌ 持续远离，-1分 |
| ③ 新高新低比 | 创新高 > 创新低 | 创新低持续增加 | ❌ 创新低暴增，-1分 |
| ④ 板块效应 | 3个以上板块涨幅>1% | 全部板块转绿，无一翻红 | ❌ 全部翻绿，-1分 |
| ⑤ 量价配合 | 上涨放量/下跌缩量 | 下跌放量（恐慌盘涌出） | ❌ 创业板爆量，-1分 |
| ⑥ 权重股 | 茅/招/中芯等翻红撑盘 | 权重全线下跌，无一翻红 | ❌ 仅长江电力勉强平盘，-1分 |

**评分与仓位对应：**
```
+6~+4分 → 🟢 强势市场，仓位80-100%
+3~+1分 → 🟡 正常震荡，仓位50%
 0~-2分 → 🟡🔴 弱势市场，仓位30%
-3~-4分 → 🔴 调整/恐慌，仓位10-20%
-5~-6分 → 💀 系统性风险，空仓或≤5%

6/26 11:00评分：-6分（全部6因子全部为负）→ 💀 系统性风险
```

#### 阶段四：下午预判（13:00-14:30）

| 上午走势类型 | 下午大概率 | 操作 |
|:-----------|:---------|:----|
| 单边下跌无反弹 | 继续跌或弱横盘 | 减仓到最低，不留隔夜仓 |
| 先跌后V型反弹 | 下午可能二次探底or持续修复 | 如果V后站稳→可持有 |
| 横盘震荡 | 波动不大，尾盘决定方向 | 正常操作 |
| 单边上涨 | 下午可能冲高回落or持续 | 持有但设止盈 |

**下午关键时间窗口：**
```
13:00-13:30  惯性延续（上午的方向通常会惯性延续30分钟）
13:30-14:00  第一次抵抗（如果上午跌，13:30-14:00是反弹窗口）
14:00-14:25  真实方向（反弹失败→尾盘还要跌；反弹成功→修复）
14:25-14:50  尾盘博弈（最后25分钟决定收盘形态）
14:50-15:00  收盘定局
```
