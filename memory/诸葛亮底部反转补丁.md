## 新增DNA维度：底部反转评分（0-20分加分项）

### 条件（全部满足才触发，额外+20分）

| 条件 | 阈值 | 检测方法 |
|:----|:----|:--------|
| 近1年高点跌幅 | ≥30% | K线250日最高 vs 现价 |
| 底部不创新低 | 连续10日 | 近10日最低 ≥ 前10日最低 |
| 站上20MA | 收盘价 > 20MA | 对比收盘价和20日均线 |
| 5日量比 | 1.3x ~ 1.8x（温和放大） | 近5日均量 / 20日均量 |
| 事件驱动 | 90天内有催化 | 刘备验证 |

### 与原有DNA的关系

```
原DNA五维（0-100） + 底部反转加分（0-20） = 新DNA总分（0-120）

≥90分（含底部加分）→ 长期池候选，优先级最高
≥70分（不含底部加分）→ 原长期池标准
50-69分 → 交汉武帝短线候选
```

### 应用场景

当大盘连续下跌后出现反弹窗口时，这个维度自动激活，优先筛选超跌+有催化的标的。大盘正常时关闭，避免误选纯超跌垃圾股。

## 源于模式1的关键条件入库

- ✅ 跌幅≥30% → DNA逆势强度维度加分
- ✅ 连续不创新低 → DNA独立性维度加分
- ✅ 温和放量 → DNA资金信号维度加分
- ✅ 有事件催化 → 纳入刘备验证流程
- ⚠️ 股东人数下降/套牢盘占比 → 数据源待打通，暂标记为"待验证"
