## 曹操监视规则（最高优先级）

1. 检查每个模型是否使用**真实脚本**运行，不是手写结论
2. 检查每个模型的数据来源是否来自**指定API**，不是编造数据
3. 检查每个模型的输出是否附带**原始数据出处**，不是凭空叙述
4. 发现违规 → 记录违规台账 → 通知用户
