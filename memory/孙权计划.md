| 项目 | 值 |
|:----|:----|
| 总分 | **100分** |
| 入选备选池 | **≥78分** |
| 直接剔除 | **＜70分** |
| 生效前提 | 板块批量异动，个股单独脉冲直接放弃 |
| 适用场景 | 催化题材短线隔夜，禁止用于模式A趋势股 |

## 所需数据源

1. 股票代码
2. 14:45快照现价
3. 实时流通市值（亿元）
4. 14:45累计成交额（9:30-14:45）
5. 20日日均成交额
6. 近60个交易日日线（统计自然涨停，剔除一字板）
7. 筹码分布：全部密集筹码峰对应价格
8. 未来3个月公告：解禁、减持、监管问询、ST、立案信息
9. 14:45当日分时均价

## 套牢区间计算标准（严格照此执行）

**目标价格上限 = 现价 × 1.20**

**判定逻辑：**
查找所有密集筹码峰价格；
任意一组密集筹码峰价格 ≤ 目标价格上限 → 认定【现价向上20%内存在密集套牢峰】

**示例：** 现价10元，上限12元。只要有密集筹码峰价格处于10~12元区间，即为近端套牢。

---

## 前置粗筛（步骤1：打分前执行，满足任意一条直接剔除，禁止进入后续打分）

> ⚠️ **强制执行顺序，不可颠倒。必须先筛、再打分。禁止先打分再过滤。禁止输出已剔除个股到候选清单。**

1. **流通市值 ＜ 40亿** → 剔除
2. **现价向上20%价格区间内存在密集筹码峰** → 剔除
3. **当日已经涨停封板个股** → 剔除

---

## 五维打分（步骤2：仅前置粗筛通过后才允许启动）

> ⚠️ 只有通过步骤1的个股，才进入本步骤打分。禁止先打分再过滤。

### 维度1：流通市值｜30分

| 条件 | 分值 |
|:----|:----:|
| 40亿 ≤ 流通市值 ≤ 150亿 | **30分** |
| 150亿 < 流通市值 ≤ 250亿 | **18分** |
| 流通市值 ＞ 250亿 | **6分** |

### 维度2：历史股性｜25分

**统计**：近60个交易日自然涨停，剔除一字板

| 条件 | 分值 |
|:----|:----:|
| 涨停 ≥ 5次 | **25分** |
| 涨停 3~4次 | **16分** |
| 涨停 1~2次 | **8分** |
| 0次涨停 | **0分** |

**补充**：频繁烂板、涨停次日持续性弱，额外扣6分

### 维度3：预估量能｜20分（核心）

**固定快照时点**：14:45，禁止使用收盘数据

**已交易时长**：9:30–14:45 合计 215 分钟

**预估公式**：
```
预估全天成交额 = 14:45累计成交额 ÷ 215 × 240
比值 = 预估成交额 / 20日日均成交额
```

| 条件 | 分值 |
|:----|:----:|
| 1.2 ≤ 比值 ≤ 2.0 | **20分** |
| 1.0 ≤ 比值 < 1.2 或 2.0 < 比值 ≤ 2.8 | **12分** |
| 比值 < 1.0 或 比值 > 2.8 | **5分** |

**强制规则**：14:45之后尾盘突击拉涨放量，此项直接5分

### 维度4：远端套牢筹码｜15分

经过前置粗筛后剩余标的适用：

| 条件 | 分值 |
|:----|:----:|
| 现价向上 > 35% 才出现密集套牢峰 | **15分** |
| 现价向上 20%~35% 区间存在密集套牢峰 | **6分** |

### 维度5：潜在利空｜10分

| 条件 | 分值 |
|:----|:----:|
| 未来3个月无大额解禁、减持、问询、ST | **10分** |
| 小额减持、解禁距离当前 > 3个月 | **4分** |
| 临近解禁、清仓减持、问询、ST预期 | **0分** |

## 同分人工筛选条件（不计分，择优排序）

1. 主营直接受益题材 ＞ 深度合作 ＞ 参股蹭热点
2. 概念通俗易懂，辨识度高
3. 股价处于回调后低位，避开高位震荡
4. 14:45价格站稳当日均价线上方

---

## 模型禁令

1. 无题材催化的平淡交易日不运行模型
2. 不可用于模式A底部箱体趋势股筛选
3. 严禁用收盘成交额替换14:45预估值
4. 模型仅输出打分结果，不自动下达买卖指令

---

## 输出格式

```
股票代码｜市值得分｜股性得分｜量能得分｜套牢得分｜利空得分｜总分｜是否达标｜风险备注
```

## 操作流程

| 时间 | 动作 |
|:----|:------|
| 14:30 | 前置粗筛（市值+套牢）+ 初次量能预估 |
| 14:45 | 最终量能判定 → 五维评分 → ≥78分入池 |
| 14:50 | 人工二次排序（题材/辨识度/K线/分时） |
| 14:55 | 终榜 ≤3只 → 尾盘买入 |
| 次日09:25 | 竞价复核，不及预期放弃 |
| 次日 | 板块延续→持有；板块退散→止盈；触及-5%止损→核按钮 |
