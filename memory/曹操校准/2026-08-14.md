### 病根：评分奖励"昨天已兑现的资金"，赌的却是"明天"

```
孙权潜伏模式灵魂 = 买没启动的票，赌明天被游资拉
板块资金维度 20分 = 关羽"当天资金流入方向"
→ 当天资金强 = 已经price in = 次日反而危险（永安）
→ 当天资金弱 = 潜伏机会 = 次日可能启动（蓝箭）
```

- 8/13：医药强（ETF+1.00%·+36亿）→ 永安满分20/20 → 8/14医药熄火 -1.12%
- 8/13：半导体弱（ETF 0.00%·暗流TOP无）→ 蓝箭扣分 → 8/14半导体启动 +15.14%

### 判定

- 不是孙权算错：8/13当天数据下永安确实"更完美"，是**数据口径选错**
- 是系统性问题：**用当天板块资金预测次日轮动方向，在轮动市里系统性失效**
