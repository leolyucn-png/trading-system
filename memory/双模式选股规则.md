# A股双模式选股规则与交易策略 v1.0

> 固化日期: 2026-07-16 | 用户亲授
> 与汉武帝短线系统平行运行，互不干扰

---

## 核心任务

每日盘后自动扫描全A股，输出两个独立标的池：
- **底部反转埋伏池**（事件驱动，赚预期差修复）
- **趋势回踩优质池**（基本面打底，赚成长溢价）

每只标的同步标注：核心逻辑、买入区间、止损位、止盈参考、风险提示。

---

## 模式1：底部反转埋伏池

### 1. 硬性筛选条件（全部满足）

| 条件 | 阈值 |
|:----|:-----|
| 价格位置 | 较近1年高点跌幅≥30% |
| 底部区间 | 处于近200日底部区间 |
| 不创新低 | 连续10个交易日不创新低 |
| 站上均线 | 收盘价站稳20日均线 |
| 流动性 | 近20日日均成交额≥1亿元 |
| 市值 | 50-500亿 |
| 排雷 | 无ST/退市风险/大额商誉减值/连续两年亏损 |

**筹码加分项：**
- 近2季度股东人数累计降幅≥5% 优先
- 上方套牢盘占比≤30%

### 2. 核心催化（必备）

- 未来90天内有明确可落地的确定性事件
- 标的为事件核心受益方，剔除边缘蹭概念
- 事件尚未全市场官宣，市场讨论度低，存在预期差

### 3. 启动买点确认

- 近5日成交量较20日均量温和放大30%-80%（非单日爆量）
- 大盘/板块创新低时个股不跟跌（独立止跌属性）

### 4. 交易规则

| 操作 | 规则 |
|:----|:-----|
| 建仓 | 事件落地前20-30天分2批买入 |
| 止损 | 跌破近期最低点下方3%，无条件离场 |
| 止盈 | 事件官宣前3-5天分批止盈，事件落地当日清仓 |

---

## 模式2：趋势回踩优质池

### 1. 硬性筛选条件（全部满足）

| 条件 | 阈值 |
|:----|:-----|
| 趋势形态 | 近3个月低点逐步抬高，上升通道 |
| 累计涨幅 | ≤60%（排除高位加速） |
| 流动性 | 近20日日均成交额≥2亿元 |
| 市值 | 80-800亿 |
| 基本面 | 高景气赛道+扣非净利润同比正增长或拐点 |
| 机构持仓 | 前十大含机构/公募/社保（排除纯庄股） |

**行情加分项：**
- 近1个月涨幅显著跑赢所属板块（独立行情属性）

### 2. 回踩买点确认

- 股价回踩20/30日均线
- 当日成交量缩至5日均量的60%以下
- 收小阳/十字星，不跌破前期回调低点

### 3. 交易规则

| 操作 | 规则 |
|:----|:-----|
| 建仓 | 回踩确认后分批买入 |
| 止损 | 放量跌破30日均线且3日内无法收回，无条件离场 |
| 止盈 | 每创新高分批止盈；全市场一致唱多+单日爆量3倍+收长上影=清仓 |

---

## 绝对禁止买入清单

触发任意一条直接剔除：
1. 连续3个及以上涨停的纯题材股
2. 公司发布股票交易异常波动风险提示公告后
3. 高位单日换手率超20%、成交量爆量3倍以上
4. 无基本面支撑、纯情绪炒作的亏损题材股
5. 近20日日均成交额低于8000万的低流动性标的

---

## 通用风控铁则

| 规则 | 内容 |
|:----|:-----|
| 仓位 | 单票≤15%总资金，单板块≤30% |
| 游资 | 龙虎榜游资仅作情绪验证，不作为买入依据 |
| 回测 | 每月末自动回测当月胜率，<50%触发预警 |
| 逻辑锁 | 买入前必须标注对应交易模式，禁止盘中切换逻辑 |

---

## 每日输出格式

按两个池子分类输出，每只标的包含：
- 股票名称 + 代码
- 核心驱动逻辑
- 当前价格
- 建议买入区间
- 止损位
- 止盈参考
- 核心风险点
