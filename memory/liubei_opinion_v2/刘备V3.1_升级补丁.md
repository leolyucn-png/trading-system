## 一、新增能力1：社交媒体异常检测 🔥

### 背景
```
中公教育 2026-07-02：散户在股吧打了黄赌"涨不到20块让各位搞一次"
→ 帖子爆炸传播 → 7/5热搜第一 → 周一大概率秒板

旧刘备：无法发现这种信号
新刘备：帖子回复量异常→自动报警
```

### 检测维度

| 维度 | 数据源 | 异常阈值 |
|:----|:----|:--------|
| 股吧帖子回复增速 | 东方财富股吧 | 1小时内回复>500%增幅 |
| 同花顺论股热度 | 10jqka | 进入个股热门前20 |
| 雪球讨论量 | xueqiu | 当日帖子数>前5日均值3倍 |
| 东方财富关注度排名 | eastmoney | 排名突然跳升>50位 |

### 工作流
```
09:00/10:30/11:30/14:00 定时扫描：
  → 抓取东财/同花顺/雪球全A股讨论量
  → 对比前5日均值
  → 任何个股讨论量>均值3倍 → 🚨报警
  → 查看帖子内容摘要 → 判断是利好/利空/段子
  → 写入刘备警报日志
```

## 二、新增能力2：热搜排名追踪 📊

### 数据源
```
东方财富热搜榜 → 个股关注度排名
同花顺热榜 → 搜索/讨论热度排名
百度指数 → 搜索量趋势（如可接入）
```

### 监控规则
```
每30分钟刷新一次热搜排名：
  → 新进入TOP50的票 → 标记🆕
  → 排名跳升>30位的票 → 标记🚀
  → 连续3天在TOP10的票 → 标记过热⚠️
  → 突然掉出TOP100的票 → 标记冷却❄️
```

### 联动逻辑
```
热搜异动 → 刘备验证原因 → 分发结果：
  → 段子/口嗨型热搜 → 给张飞（反人性判断是否游资会借机点火）
  → 政策/利好型热搜 → 给关羽（验证资金是否已提前进场）
  → 负面利空型热搜 → 给大乔（是否需要减仓）
```

## 三、新增能力3：龙虎榜监控 🐉

### 数据源
```
东方财富龙虎榜 → 每日上榜股票+席位明细
同花顺龙虎榜 → 游资/机构买卖方向
```

### 监控维度

| 维度 | 看什么 | 意义 |
|:----|:----|:----|
| 游资席位 | 知名游资今天买了谁 | 短线方向信号 |
| 机构席位 | 机构净买入>5000万 | 中线配置信号 |
| 游资接力 | 同一只票连续2天上榜 | 游资在造势 |
| 游资一日游 | 昨天买今天卖 | 出货信号 |
| 散户接盘 | 买入前5全是散户席位 | 危险信号 |

### 每日定时任务
```
15:30 收盘后：
  → 拉取当日龙虎榜全量数据
  → 识别：哪些票被游资净买入>3000万
  → 识别：哪些票被机构净买入>5000万
  → 识别：哪些票游资昨天买今天卖（一日游）
  → 交叉验证：热搜榜上的票是否出现在龙虎榜上
  → 写入 memory/liubei_opinion_v2/longhubang/YYYY-MM-DD.md
```

### 联动其他模型
```
龙虎榜游资买入 → 
  → 关羽：验证是否有资金流入配合
  → 诸葛亮：是否在候选池或样本库
  → 小乔：游资进场后是否构成买点
  
龙虎榜游资卖出 → 
  → 大乔：加速卖出信号
  → 张飞：是否一致性出货
```

## 六、铁律

```
1. 段子/口嗨型热搜 → 只通知张飞判断，不直接给买入建议
2. 热搜 ≠ 买入信号 → 热搜是关注度，不是方向判断
3. 龙虎榜游资净买入 → 需关羽资金流验证才能作为买入依据
4. 游资一日游 → 自动标记该席位为"不跟"
5. 名人/大V提及 → 需区分"带货"和"真实看好"
6. 所有社交信号 → 必须先过张飞反人性筛选
```
