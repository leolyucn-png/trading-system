
## 模块零：双运行模式（🆕 V3.2核心，解决新闻滞后致命矛盾）

### ① 前置预判模式（高价值，唯一可输出埋伏参考）

```
信息来源限制：
  仅依靠冷门信息池、未公开产业调研纪要、地方政策草案、海外小众产业数据
  不使用全网头条官宣新闻

生效硬性门槛（全部满足）：
  □ 关羽同步捕捉持续小额资金流入
  □ 题材生命周期总分≤40分，处于萌芽/扩散早期
  □ 无大规模自媒体、股吧集体吹票，情绪一致性指数＜60%
  □ 热度抬升来自产业隐性线索，而非公开利好落地

模式优待规则：
  → 自动打上【🔥低位潜伏题材】专属标签
  → 政策驱动得分上浮0.2
  → 内置仓位参考系数上浮20%
  → 存入独立潜伏观察池持续跟踪

自动失效条件（任意一条触发立刻切换为事后验证）：
  □ 对应政策/产业利好发布官方完整公告
  □ 3家及以上主流财经媒体头条同步报道
  □ 情绪一致性指数突破60%
  □ 题材生命周期总分突破40分进入发酵期
```

### ② 事后验证模式（仅风控复盘，无新开仓指引）

```
触发场景：
  官方政策/行业利好全网公开发布
  无提前小众产业线索铺垫
  行情已提前炒作

硬性约束：
  → 不再生成任何低位埋伏标记
  → 不输出新开仓、分批入场建议
  → 内置参考仓位强制压缩至原值30%
  → 仅服务历史持仓止盈规划
  → 发酵/高潮/分歧期题材统一叠加【预期透支】风险标签

报告强制红字提示（固定头部文字）：
  ⚠️红字预警：本验证依托全网落地公开消息，滞后资金炒作周期1~3个交易日，
  题材大概率存在情绪透支，禁止新开仓，仅可对已有持仓做止盈评估。
```

所有数据源均带精确时间戳，系统自动按研判时间切片，禁止读取切片后的数据。

### 1. 官方政策库
- **采集源**：国务院、国常会、工信部、发改委、证监会、财政部、医保局等部委官网，财联社/上证报政策快讯
- **更新频率**：交易日5分钟/次，非交易日30分钟/次
- **采集字段**：发布主体、政策级别、核心内容、市场此前预期、发布时间
- **降级方案**：官方源失效→财联社电报→新浪财经→东方财富

### 2. 上市公司事件库
- **采集源**：巨潮资讯网公告、交易所互动易、调研纪要
- **采集字段**：公告类型、业绩、订单、减持、解禁、专利、合作
- **更新频率**：每日早间全量更新，盘中实时监控异动公告

### 3. 社交媒体舆情池
- **采集平台**：雪球、东方财富股吧、微博财经话题、抖音财经、知乎财经
- **采集字段**：讨论量、看多/看空评论数、热度环比增速、头部账号观点
- **统计口径**：单题材单平台有效评论量、看多占比、24小时热度环比

### 4. 外围联动信息库
- **采集源**：A50期指、美股三大指数、美债收益率、人民币汇率、海外产业重大新闻
- **更新频率**：实时同步
- **用途**：早盘开盘情绪预判、外部风险预警

### 5. 冷门信息池（未发酵题材核心来源）
- **采集源**：券商小众研报、细分行业会议纪要、地方产业政策、海外小众产业资讯
- **筛选标准**：全平台讨论量低于全市场题材20%分位，无头部媒体转载
- **用途**：挖掘萌芽期潜在题材，提前埋伏

### 6. 板块行情与资金库
- **采集源**：AkShare / Tushare
- **字段**：行业/概念板块涨跌幅、主力净流入、成交额占比、ETF申赎份额、两融余额
- **用途**：舆情+资金双验证，杜绝伪题材

### 7. 龙虎榜席位库
- **采集源**：交易所每日龙虎榜
- **字段**：机构席位净买卖、知名游资席位买卖、一日游资金占比
- **用途**：验证题材资金性质，区分机构行情与游资一日游

### 8. 研报预期库
- **采集源**：券商研报汇总
- **字段**：近7日题材研报数量、看多占比、目标价上调幅度
- **用途**：计算机构一致预期率，识别见顶信号

## 模块二：政策分级与预期差量化体系（适配A股政策市）

### 1. 政策层级五级加权（权重不可修改）

| 级别 | 权重 | 发布主体 |
|:----|:---:|:--------|
| **国家级** | **1.0** | 中共中央、国务院、国常会、中央深改委、中央财经委发布的顶层规划/政策 |
| **部委级** | **0.7** | 国务院组成部门（工信部、发改委、证监会等）发布的正式行业文件 |
| **地方级** | **0.4** | 省/直辖市/计划单列市发布的地方产业补贴、扶持政策 |
| **行业级** | **0.2** | 行业协会、交易所发布的指引、规范 |
| **公司级** | **0.1** | 单个上市公司公告、合作、专利 |

### 2. 预期差三级判定

对比政策内容与发布前市场一致预期，计算预期差系数：

| 判定 | 系数 | 条件 |
|:----|:---:|:-----|
| **超预期** | **+0.5** | 补贴力度、覆盖范围、落地时间显著好于市场此前共识 |
| **符合预期** | **0** | 内容与此前传闻、吹风基本一致 |
| **低于预期** | **-0.5** | 政策力度弱于市场预期 |

### 3. 政策驱动最终得分

```
最终得分 = 政策层级权重 × (1 + 预期差系数)

> 0.8  → 强驱动题材，具备中期行情潜力
0.4-0.8 → 弱驱动题材，短期脉冲为主
< 0.4  → 无效驱动，忽略不计
```

## 模块三：题材生命周期六阶段前置判定

总分0-100分，结合舆情热度、资金强度、市场表现三维度量化。

### 阶段1：萌芽期（0-20分）【前置埋伏窗口】
| 维度 | 特征 |
|:----|:------|
| 舆情 | 全平台讨论量处于全市场题材后20%分位，仅1-2家小众媒体提及 |
| 资金 | 板块主力净流入连续2日为正，累计涨幅＜3%，龙头首板或连续小阳线 |
| 市场 | 观点高度分歧，多数人质疑逻辑 |
| **操作** | **单题材仓位≤10%，试错埋伏** |

### 阶段2：扩散期（21-40分）【加仓跟进窗口】
| 维度 | 特征 |
|:----|:------|
| 舆情 | 小众财经批量转载，讨论量环比翻倍，仍有大量分歧观点 |
| 资金 | 板块持续净流入，出现2-3只连板龙头，板块涨幅3%-8% |
| 市场 | 部分机构开始覆盖，散户逐步关注 |
| **操作** | **单题材仓位≤20%，顺势加仓** |

### 阶段3：发酵期（41-60分）【持有为主窗口】
| 维度 | 特征 |
|:----|:------|
| 舆情 | 主流财经媒体全覆盖，登上涨幅榜前列，讨论量进入前30% |
| 资金 | 板块成交额占全市场5%以上，批量涨停，龙头持续连板 |
| 市场 | 看多观点逐步占据主流 |
| **操作** | **单题材仓位≤30%，持有为主，不追高** |

### 阶段4：高潮期（61-80分）【分批减仓窗口】
| 维度 | 特征 |
|:----|:------|
| 舆情 | 全网刷屏，自媒体集体吹，登上微博/抖音热搜 |
| 资金 | 板块成交额创阶段新高，边角料概念股普涨，龙头放量滞涨 |
| 市场 | 几乎一致性看多，质疑声音被淹没 |
| **操作** | **单题材仓位≤10%，分批止盈，只卖不买** |

### 阶段5：分歧期（81-90分）【坚决兑现窗口】
| 维度 | 特征 |
|:----|:------|
| 舆情 | 炸板率飙升，看多观点出现分化，利空零星出现 |
| 资金 | 龙头高位放量断板，资金向低位补涨股扩散，板块资金净流出 |
| 市场 | 开始出现"利好兑现"的声音 |
| **操作** | **禁止新开仓，持仓逢高全部兑现** |

### 阶段6：退潮期（91-100分）【彻底规避窗口】
| 维度 | 特征 |
|:----|:------|
| 舆情 | 利好被解读为出货，负面评论快速增加 |
| 资金 | 板块批量大跌，龙头跌停，资金持续出逃 |
| 市场 | 一致性看空，套牢盘大量出现 |
| **操作** | **完全规避，不抄底、不博弈反弹** |

### A股专属补充规则

```
龙头锚定法则：
  题材高度由龙头股连板高度、封单强度决定。
  龙头出现放量断板 → 直接判定题材进入分歧期，无需等全板块下跌。

扩散末端法则：
  题材从龙头→核心标的→上下游→边角蹭概念扩散完成
  → 判定进入高潮末期 → 资金即将高低切换
```

## 模块四：预期透支与一致性反身性判定（专治周末高开套人）

三大量化指标，**任意满足2项，直接判定「预期完全透支」**，强制输出"禁止开盘追高，逢高减仓"，优先级高于所有正向逻辑。

### 指标1：情绪一致性指数

```
公式：看多评论数 / 有效评论总数 × 100%

> 80%  → 高度一致，利好兑现风险>70%
60%-80% → 偏一致，存在兑现压力
< 60%  → 分歧充分，行情可持续
```

### 指标2：研报一致预期率

```
公式：近7日看多研报数 / 近7日该题材总研报数 × 100%

> 75% → 机构集体唱多，典型见顶信号
```

### 指标3：周末消息浓度

```
公式：周末相关利好消息条数 / 近5个工作日日均消息条数

> 200% → 消息集中爆发，全市场预期透支，周一高开回落概率极大
```

### 专项规则：周日20:00固定执行

```
执行本模块全量计算，输出《周一开盘专项预判报告》：
  □ 高开/低开概率
  □ 高开回落风险等级
  □ 可操作/需规避题材
```

## 模块五：A股特有风险前置预警

触发任意一项，对应题材正向舆情得分直接减半，风险等级上调一级。

### 1. 监管异动风险
- **个股**：10天内4次异动公告、收到问询函/监管函、列入严重异常波动名单
- **行业**：出现集采、反垄断、价格管制、限产等限制性政策
- **市场**：证监会/交易所表态严打概念炒作、异常交易

### 2. 伪利好识别
上市公司发布利好公告，同时伴随以下任意一项 → 判定为伪利好，不计入正向舆情：
- 近7日发布股东减持公告
- 近15日内有限售股解禁
- 高管发布减持计划

### 3. 业绩雷预警
财报披露窗口期（1月、4月、7月、10月中下旬），高位题材股业绩增速低于市场一致预期 → 标记为业绩高危，披露前强制提示减仓。

## 模块六：高低切舆情前置预判引擎

### 1. 触发条件（自动启动）
主线题材进入分歧期/退潮期（得分>80分 + 龙头断板 + 资金连续2日流出），自动启动全市场低位板块扫描。

### 2. 低位轮动候选筛选标准（全部满足）
- 近30日板块累计跌幅>15%，处于近半年价格低位区间
- 舆情热度连续3日缓慢抬升，仍处于全市场后40%分位
- 主力资金连续2日逆势净流入，区间累计涨幅<5%
- 具备防御属性（医药、消费、公用事业）或政策边际改善预期

### 3. 跷跷板验证

```
公式：跷跷板系数 = 主线资金净流出额 / 低位板块资金净流入额

0.8-1.2  → 典型资金跷跷板，高低切换确定性高
< 0.8    → 低位承接资金不足，切换持续性弱
> 1.2    → 主线流出资金未全部流入低位，存在资金离场观望
```

## 🆕 模块十四：V3.2重大重构（2026-07-02 16:18）

### 核心变化

V3.2 彻底解决「新闻滞后导致接盘」的根本矛盾：

```
旧架构问题：
  刘备看到新闻 → 验证催化真实 → 汉武帝/刘彻买入
  但：新闻滞后1-3天 → 买入时已经在高位

V3.2解决方案：
  ① 双运行模式分离
    前置预判模式：只用冷门信息+资金验证 → 可以输出买入
    事后验证模式：全网公开新闻 → 只做风控，禁止买入
  
  ② 短线模式不再启动刘备
    汉武帝/刘彻 T+1 → 不经过刘备（新闻太慢）
    诸葛亮 2周+ → 经过刘备（催化验证有价值）
```

### 双模式切换规则

```
前置预判 → 事后验证 自动切换条件：
  □ 政策/产业利好发布官方完整公告
  □ 3家以上主流媒体头条同步报道
  □ 情绪一致性指数突破60%
  □ 题材生命周期突破40分进入发酵期

事后验证→前置预判 不自动切换：
  事后验证模式一旦进入，本轮不再切回
  等下一轮关羽资金异动→重新评估
```

### 采集优先级（新分档）

```
1档（前置预判专用）：冷门信息池
2档（事后核验专用）：官方政策库、上市公司事件库  
3档（行情佐证）：社交媒体、外围联动、龙虎榜、研报库、资金库
```

### 更新后的输出模板关键变化

```
事后验证模式强制头部红字：
  ⚠️ 本验证依托全网落地公开消息，滞后资金炒作周期1~3个交易日
  题材大概率存在情绪透支，禁止新开仓，仅可对已有持仓做止盈评估

潜伏题材附加约束：
  若热度上涨核心驱动力为全网公开落地新闻
  → 剥夺【🔥低位潜伏题材】标签 → 划入事后验证清单
```

### 与汉武帝/刘彻的隔离规则

```
✅ 汉武帝/刘彻启动 → 不经过刘备
   原因：T+1短线靠资金流，新闻1-3天滞后是毒药

✅ 诸葛亮启动 → 经过刘备
   原因：2周+持有期，催化验证有长期价值
```

```
  fixed_warning: "⚠️红字预警：本验证依托全网落地公开消息，滞后资金炒作周期1~3个交易日，题材大概率存在情绪透支，禁止新开仓，仅可对已有持仓做止盈评估。"
```
