## 二、为什么卖不好——根因拆解

### 共同病根：用「计划」替代了「判断」

```
旧系统逻辑：
  ① 买的时候定好目标价（止盈/止损）
  ② 到了就执行，不问为什么

但市场是流动的：
  买的时候大盘4000点
  卖的时候大盘4085点+科创+3.6%
  条件变了，计划没变
```

### 旭光的具体问题

```
我们在旭光上的表现：
  6/8 暴跌到23.76 → 抗住了没卖 ✅（这是对的）
  6/9→6/10 反弹到27 → 没卖（也是对的）
  6/11 涨停29.94 → 开始想卖（问题来了）
  6/12 竞价冲到32.27 → 该锁没锁 → 收盘28.69
  6/15 再涨停31.56 🚀

根因：
  我们看到了"好票"的特征（一月三涨停）
  但不会判断好票的卖点在哪
  以为涨停就是顶，结果只是半山腰
```

### 晶方的具体问题

```
我们在晶方上的表现：
  6/5→6/12 从48跌到40.98，一直扛着亏 ✅
  6/15 反弹到43+ → 按计划43-44减仓 → 卖了
  然后它一路冲到44.13

根因：
  看到了盘口买盘1.92倍、大单托着
  看到了科创50+3.6%、资金在科技
  但计划说"43-44减" → 就执行了
  没有让"盘口资金行为"推翻"老计划"
```

## 三、新系统的修正

### 新增「持续买盘承接」检查

每次到目标价时，先检查：

```
盘中低点在抬高吗？
每次跌都有人接吗？
反弹高点在抬高吗？

如果全YES → 资金在吸筹 → 不卖
如果部分YES → 分级卖出
如果全NO → 按计划执行
```

### 新增「好票卖点」规则

```
对于已确认的"好票"（如旭光—模式18反复涨停）：
  不设固定止盈
  改用移动止盈（trailing stop）
  用法：从最高点回落-5%才卖
  案例：旭光6/12最高32.27 → 回落5%=30.66
        如果6/12收盘28.69跌破30.66 → 触发卖出
        而不是在29.94就卖了
```
