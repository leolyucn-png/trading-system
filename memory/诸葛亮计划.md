# 🏯 诸葛亮计划 v7.0 — 可复制的独立牛股筛选模型

> 版本：v7.0 | 更新时间：2026-06-23 12:30
> 基于v6.0全面重构，核心从"旭光模仿秀"升级为"可复制的独立牛股筛选模型"

---

## 一、顶层定位

```
旧定位（v6.0失效）：找"像旭光"的票 → 单案例模仿，容易过拟合
新定位（v7.0）：找"具备独立走强DNA"的票 → 基于多牛股样本的共性特征筛选

核心原则：
  ① 宁缺毋滥：活跃池最多3只，凑不够就空着
  ② 量化优先：所有特征全部可计算，禁止主观判断
  ③ 数据说话：所有标准经过历史回测验证，胜率>60%才保留
```

## 二、牛股样本库（已建立）

- 文件：`memory/牛股样本库.md`
- 正式入库：8只 | 参考入库：3只
- 覆盖板块：军工电子、半导体材料、PCB、光通信、新材料
- 核心逻辑：全部在硬科技赛道，独立走强特征高度一致

## 三、牛股DNA标准 v7.0（已建立）

- 文件：`memory/牛股DNA标准_v7.0.md`
- 5大量化维度：逆势强度 >30% / 独立性 ≥2分 / 资金异常 ≥2分 / 筹码集中 >15% / 龙虎榜 ≥1分
- 硬性通过：维度1+维度2同时通过 → 直接进入候选
- 总分公式：100分制（30+25+20+15+10）

## 四、每日3步流程（v7.0精简版）

### 第1步：全市场量化初筛（15分钟）

**工具：** 腾讯API实时行情 + 牛股DNA维度1-2快速计算

**操作：**
```
☐ 拉取全A股（主板+中小板+创业板）实时数据（涨跌幅/换手率/量比/内外盘）
☐ 计算维度1：个股涨幅 - 板块预估涨幅（用ETF均值代替）
☐ 计算维度2：大盘跌时个股是否跟跌（快速判断）
☐ 前20名进入初筛名单
```

**输出：** 初筛名单20只 + 每只维度1-2得分

**跳过条件：** 数据源全部挂 → 标注"数据缺失" → 跳过本日初筛

---

### 第2步：精选 + 逻辑验证（20分钟）

**工具：** web_search + 基本面检查 + stock-news-hunter

**操作：**
```
☐ 从初筛20只里，深度分析前10只（维度3-5计算）
☐ 验证"独立逻辑"：是真有自身逻辑，还是板块带动？
☐ 基本面排查：减持/问询/ST/解禁/业绩暴雷
☐ 反共识检查：是不是所有人都在讨论的热门票？
☐ 删除排除项：跟风杂毛/当天新闻追高/板块过热
```

**输出：** 精选3-5只 + 每只逻辑验证报告


## 五、候选池分层规则

| 层级 | 数量上限 | 准入标准 | 操作 |
|:----|:-------:|:--------|:----|
| 🟢 活跃池 | **3只**（严格上限） | 全部满足5条DNA标准 | 主动推荐给汉武帝 |
| 🟡 验证池 | 不限 | 汉武帝实盘验证赚钱+逻辑仍在 | 每日扫描，到支撑位通知 |
| 🔵 观察池 | 不限 | 初筛通过但未达活跃池标准 | 每周观察，达标升级 |

**铁律：活跃池宁空勿滥，3只上限是硬约束。不凑数。**

---

## 六、持仓周期

| 周期 | 规则 |
|:----|:----|
| 最短 | **5个交易日**（给逻辑发酵时间） |
| 最长 | **20个交易日**（过时不涨=判断错，剔除） |
| 止损 | 触发即剔除，不格局 |

**理由：** 10天以内=短线范畴归汉武帝；2-4周刚好是一个独立逻辑从发酵到兑现的完整周期。

```
如果整体胜率<60% → 调整DNA标准重新回测
回测不通过 → 这套模型不能实盘用
```

## 八、防偷懒 / 防主观强制执行规则

```
□ 禁止主观判断：所有筛选必须基于量化得分
  "我觉得""应该是"等表述 = 违规 → 全部重写
□ 禁止凑数：活跃池不够3只就空着
□ 禁止事后解释：所有预判必须在涨之前输出
  涨了之后再找理由 = 作弊 → 本条预判作废
□ 每周强制回测：每周日跑一次回测
  胜率<60% → 立即暂停实盘，调整DNA标准
□ 输出必须附数据：每只推荐票附带5项DNA得分
  没数据 = 作废
```
