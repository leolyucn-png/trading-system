## 新增：事件驱动埋伏模块

### 激活条件

刘彻日常扫描中，若某板块连续3日放量不涨/暗流 → 自动激活事件驱动模块：

```
① 查该板块未来90天是否有确定性事件
  - 行业政策落地（国新办发布会、十五五规划等）
  - 重磅新品发布（苹果/Meta/华为等新品周期）
  - 行业展会（COMPUTEX/WAIC/车展等）
  - 电影/体育赛事（影视板块）

② 判定标的是否是核心受益方
  - ✅ 直接供应商/合作伙伴（如: Meta建数据中心→光模块直接受益）
  - ❌ 蹭概念的边缘标的（如: 大会在大连开→大连本地股=不相关）

③ 事件是否已全市场官宣
  - 已官宣 → 🟡 部分Price In，埋伏价值打折
  - 未官宣 → 🚨 高预期差，优先级别最高
```

### 与原放量不涨检测的关系

```
放量不涨（纯资金） → 发现有资金在买
    ↓
事件驱动验证（新增） → 判断为什么在买
    ↓
    ┌─ 有事件 + 未官宣 → 最佳埋伏窗口（T-20到T-30天）
    ├─ 有事件 + 已官宣 → 短线轮动（T+1窗口）
    └─ 无事件 → 可能就是纯资金行为，不深入
```

## 刘备 V4.2 — 概念纯度+事件验证两问

刘备验证模式新增两个判定问题：

```
T+1候选每只票问:
  ① 概念纯度: 是核心受益方还是蹭概念的？
     → "在供应链里吗？有合同/订单吗？"（不是概念股）
     → 蹭概念的 → 直接降级为纸面
  
  ② 事件状态: 官宣了吗？市场讨论度多高？
     → 未官宣+讨论度低 → 🚨高预期差
     → 已官宣 → 🟡部分Price In
```
