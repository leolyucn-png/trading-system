## 📌 新增经验教训

### 🔴 模式23：C型复制陷阱（正反馈偏差）

```
现象：上一个C型（卧龙+10%）成功 → 自信 → 看到下一个"长得像"的C型 → 买入 → 亏。

本质：复制的是外形（落后板块X%），不是内核（催化+资金+龙头地位）。

判定：任何模式的重复使用 → 必须验证内核（催化三问+关羽资金+诸葛亮DNA）
      不是「上次C型赚了所以这次C型也可以」。
```

### 🔴 模式24：虚假逻辑建仓

```
现象：表面有买入逻辑（"基建补涨"/"数字中国"），深层逻辑不成立。

太极：十五五数字中国 → 五年规划，对本周涨跌无影响
中工：基建补涨 → 基建本身就无催化，补涨=无基础

判定：买入前逐字拆解逻辑链条
  "因为X → 所以Y会涨" → X是否真实/有效/有时限？
  如果X本身经不起推敲 → 逻辑=虚假 → 不买
```

### 🔴 模式25：执行铁律全线崩溃

```
现象：不是某一条规则被违反，是所有规则在同一天被违反。
根因：周五修复日+科创暴跌后的反弹兴奋+卧龙/亚玛顿清仓正反馈
     → "我们对了"的自信 → "应该多买"的冲动 → 四条铁律全破

修复：任何一天有3条以上铁律违规 → 当天禁止任何新开仓
     → 先复盘为什么违规，再决定操作
```
