## 管理规则

### 买入

```
✅ 突破临界点买入：缩量回调到关键支撑位
✅ 分批建仓：首次30%，加仓30%，最后40%
✅ 仓位上限：单只≤15%，长期池合计≤40%
```

### 持有

```
✅ 季线止损（-20%），不看日线
✅ 每周检查逻辑
✅ 不因日线波动恐慌卖出
```

### 卖出

```
⛔ 放量滞涨 3日 → 减仓50%
⛔ 逻辑证伪 → 清仓
⛔ 季线回撤-20% → 重新评估
⛔ 目标收益→锁利50%
```

### 与汉武帝边界

```
长期票 → 诸葛亮管 → 季线止损
短线票 → 汉武帝管 → 日线止损
同一只票不能同时被两个系统管
```
