# 李世民计划 — 科研管理逻辑体系

> 建立日期：2026-05-28
> 仿汉武帝计划，但用于社会科学（SSCI）学术研究

---

## 一、核心原则

### 1.1 积累 > 突击
- 每天推进一点，比憋一周写一大段更有效
- 文献管理、理论框架、数据分析同步推进

### 1.2 让数据和研究对话
- 读过的文献要留下痕迹（笔记+映射）
- 理论框架要动态更新
- 分析结果要反哺理论

### 1.3 论文是迭代出来的，不是写出来的
- 初稿永远不完美 → 改10遍就接近了
- 每周至少一次"退一步"：检查论文逻辑链是否完整

---

## 二、科研五层框架

### 第一层：文献管理 📚
- 每周扫描最新SSCI期刊（相关领域）
- 精读论文 → 写摘要+方法论+可借鉴点
- 建立文献映射表：理论→方法→领域

### 第二层：理论构建 🏗️
- 核心概念定义
- 假设推导链
- 与现有文献的对话（创新点）

### 第三层：方法论 📐
- 研究设计
- 数据来源与变量
- 分析策略

### 第四层：写作与修改 ✍️
- 结构检查（IMRaD）
- 逻辑连贯性
- 语言打磨

### 第五层：投稿策略 🎯
- 目标期刊匹配
- 审稿人预期管理
- 回复审稿意见策略

---

## 三、每日执行流程

```
09:00 ─── 今日研究目标（写一句话）
       ─── 阅读/写作/数据分析
12:00 ─── 午间复盘（进展+卡点）
14:00 ─── 继续推进
17:00 ─── 今日总结（完成什么+明天计划）
       ─── 追加到科研日志
```
