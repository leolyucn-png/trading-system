## 🆕 第七条：全球产业趋势匹配（长期持有的安全带）

> 2026-07-02 12:55 用户亲授

**核心发现：** 旭光能从25拿到48、江化微能从15拿到55、埃斯顿能持续走强，不光是因为DNA——它们都骑在一个全球性产业趋势上。

```
江化微 → 半导体材料国产替代（全球芯片产业转移中国）
旭光电子 → 军工电子+半导体器件国产化
埃斯顿 → 机器人/AI自动化全球浪潮
晶澳科技 → 新能源/光伏全球能源转型

这些趋势=3-5年级别，不会因为一个季度业绩波动消失。
正是因为有这个趋势托底，才能长期持有不恐慌。
```

### 全球产业趋势判定标准

| 趋势 | 确定性 | 持续期 | 代表票 |
|:----|:-----:|:-----:|:------|
| 半导体国产替代 | 🔴最高 | 5-10年 | 江化微/三安 |
| AI/机器人 | 🔴最高 | 10年+ | 埃斯顿/卧龙 |
| 新能源/碳中和 | 🟡高 | 10年+ | 晶澳/亚玛顿 |
| 军工现代化 | 🟡高 | 5-10年 | 旭光/楚江 |
| 海上风电 | 🟡高 | 5-10年 | 东方电缆 |

### 判断规则

```
✅ 有全球趋势托底 + 赛道龙头/潜在龙头：长期持有、季线止损
⚠️ 有趋势但不是龙头：持有、注意被龙头蚕食
❌ 无全球趋势或跟风票：按汉武帝短线处理

强制规则：
  ① 没有全球趋势背书的票不入长期池
  ② 不是赛道龙头/准龙头的票不入第一梯队
```

### 🆕 龙头判定标准

```
龙头特征：
  □ 市占率前3或技术壁垒独有
  □ 收入增速 > 行业平均
  □ 有定价权（不是价格接受者）
  □ 机构覆盖、研报密度高

潜在龙头特征：
  □ 技术领先但规模还没上来（卧龙电驱轴向磁通电机）
  □ 行业格局未定，有突围可能（亚玛顿供改窗口）
  □ 国产替代主力，市占率在爬升（江化微当时15块）
```

## 五大核心维度（全部可量化）

### 维度1：逆势强度 — 个股 vs 板块的相对收益

**定义：** 在特定时间窗口内，个股涨幅远超所属板块涨幅的程度。

**公式：**
```
逆势强度 = 个股N日涨幅 - 所属板块N日涨幅
```

**样本数据：**
| 股票 | 30日涨幅 | 板块涨幅 | 逆势强度 |
|:----|:-------:|:--------:|:-------:|
| 旭光电子 | +148% | +5% (军工) | **+143%** |
| 沃格光电 | +158% | +8% (电子) | **+150%** |
| 博云新材 | +163% | +6% (军工) | **+157%** |
| 江化微 | +91% | +10% (半导体) | **+81%** |
| 有研新材 | +61% | +12% (半导体) | **+49%** |
| 深南电路 | +65% | +8% (PCB) | **+57%** |
| 瑞斯康达 | +58% | +15% (通信) | **+43%** |
| 烽火通信 | +56% | +10% (通信) | **+46%** |

**量化阈值：** 逆势强度 > **30%**（15日窗口）/ 或 > **40%**（30日窗口）

**通过条件：** 个股涨幅 > 板块涨幅 + 30%(30日) ⚡

---

### 维度2：独立性 — 个股走势与板块的脱钩程度

**定义：** 个股在关键时段（大盘跌/板块跌）表现出与板块不同的走势。

**公式（简化版，无需相关系数计算）：**
```
独立性得分 = 
  ① 大盘跌(-1%)的日子，个股涨幅中位数 > 0 → +1分
  ② 板块跌幅前3的日子，个股不跟跌 → +1分  
  ③ 板块涨幅前3的日子，个股涨幅 > 板块2倍 → +1分
  总分0-3，≥2分通过
```

**样本验证：**
| 股票 | 大盘跌日抗跌 | 板块跌不跟 | 板块涨领涨 | 得分 |
|:----|:----------:|:---------:|:---------:|:---:|
| 旭光电子 | ✅ 6/8大盘-1.8%但抗跌 | ✅ 独立修复 | ✅ 板块弱时涨停 | 3/3 |
| 沃格光电 | ✅ | ✅ | ✅ | 3/3 |
| 博云新材 | ✅ | ✅ | ✅ | 3/3 |

**通过条件：** 独立性得分 ≥ **2分** 🔑

---

### 维度3：资金异常 — 量在价先的建仓信号

**定义：** 启动前成交量出现异常放大，但股价涨幅温和，表明资金在暗度陈仓。

**公式：**
```
资金异常得分 =
  ① 启动前5日平均成交量 > 20日均量的2倍 → +1分
  ② 同期涨幅 < 5%（温和上涨，非拉升）→ +1分
  ③ 启动前3日内外盘比 > 1.2（买盘主导）→ +1分
  总分0-3，≥2分通过
```

**样本验证：**
| 股票 | 放量>2倍 | 涨幅<5% | 买盘主导 | 得分 |
|:----|:-------:|:-------:|:-------:|:---:|
| 旭光电子 | ✅ 5/27量比5.2 | ✅ +2.1% | ✅ | 3/3 |
| 有研新材 | ✅ | ✅ | ✅ | 3/3 |
| 瑞斯康达 | ✅ | ✅ | ⚠️ | 2/3 |

**通过条件：** 资金异常得分 ≥ **2分** 💰

### 维度4：筹码集中 — 主力吸筹的股东数据验证

**定义：** 启动前股东人数持续减少，人均持股增加，表示主力在收集筹码。

**公式：**
```
筹码集中度 = (期初股东人数 - 期末股东人数) / 期初股东人数
```

**样本数据：**
| 股票 | 股东人数变化率 | 时间跨度 |
|:----|:------------:|:--------:|
| 旭光电子 | **-32%**（7.48万→5.05万） | 3个月 |
| 沃格光电 | **-25%** | 2个月 |
| 博云新材 | **-20%** | 3个月 |
| 江化微 | **-18%** | 2个月 |

**量化阈值：** 股东人数环比减少 > **15%**（2-3个月窗口）

**通过条件：** 股东人数减少 > **15%** 👥

### 维度5：龙虎榜验证 — 游资与机构的参与确认

**定义：** 启动前后有知名游资和/或机构席位出现在龙虎榜买入席。

**公式：**
```
龙虎榜得分 =
  ① 近30日有龙虎榜上榜记录 → +1分
  ② 机构席位净买入 > 1000万 → +1分
  ③ 知名游资席位（中信上海/华泰荣超等）→ +1分
  总分0-3，≥1分通过
```

**样本验证：**
| 股票 | 上榜记录 | 机构买入 | 知名游资 | 得分 |
|:----|:-------:|:-------:|:-------:|:---:|
| 旭光电子 | ✅ 6次 | ✅ | ✅ | 3/3 |
| 沃格光电 | ✅ 多次 | ✅ | ✅ | 3/3 |
| 博云新材 | ✅ 5次 | ✅ | ✅ | 3/3 |
| 有研新材 | ✅ 3次 | ✅ | ⚠️ | 2/3 |

**通过条件：** 龙虎榜得分 ≥ **1分** 🐉

## 综合筛选规则

### 候选票判定标准

| 条件 | 权值 | 通过方式 |
|:----|:---:|:--------|
| **维度1：逆势强度** > 30% | **必过** | 硬性门槛，不通过直接剔除 |
| **维度2：独立性得分** ≥ 2分 | **必过** | 硬性门槛，不通过直接剔除 |
| **维度3：资金异常得分** ≥ 2分 | **权重高** | 必过或维度4高可替代 |
| **维度4：筹码集中度** > 15% | **权重高** | 数据可得性差时可选 |
| **维度5：龙虎榜得分** ≥ 1分 | **加分项** | 不强制，但加分 |

**硬性通过（双必过）：** 维度1 + 维度2 同时通过 → 进入候选
**加权通过：** 维度1通过 + 维度2接近(1分) + 维度3+4+5 ≥ 4分 → 进入候选
**无条件剔除：** 维度1不通过，直接剔除

### 满分100分公式

```
总分 = 
  维度1(30分) + 维度2(25分) + 维度3(20分) + 维度4(15分) + 维度5(10分)
  
单项得分 = 通过(满分) / 接近(60%分) / 不通过(0分)
```

### 每日打分优先级

```
启动诸葛亮 → 维度1初筛(全市场跑) → 维度2+3精选 → 维度4+5验证
时间分配：15min + 15min + 10min = 40min
```

## ⚠️ 已知限制

1. **维度4（筹码集中）数据源：** 股东数据通常含2-3周延迟，需使用同花顺/东财F10数据
2. **维度5（龙虎榜）数据源：** 龙虎榜数据仅披露上榜日，非每日可得
3. **市场环境变化：** 该DNA标准基于2026年上半年的结构性牛市，若市场风格切换需重新校准
4. **样本偏差警告：** 8只正式样本全部集中在硬科技赛道，未覆盖消费/周期/金融等其他风格
