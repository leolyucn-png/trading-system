## ⏳ 排队③：v1.0 板块广度信号 — 2026-07-17注册【预注册·可回测】

> **来源：** 外部文档#2金子部分 · 2026-07-17龙虾处置令
> **标记：** 文档中的案例、胜率、盈亏比数字一律标注"不可验证，不作依据"

### 信号定义（预注册，可回测部分）

同一概念/板块内，同时满足以下全部条件时触发：

```
入组条件（六项全须满足）：
  ① 组内标的数：同一概念/板块内，≥3只标的
  ② 细分环节：各标的分属不同细分环节（非同类跟风）
     → 例如：同属"新能源电池"但不是全做负极，而是
        正极厂A + 负极厂B + 电解液厂C = 广度合格
        电解液A + 电解液B + 电解液C = 广度不合格（同环节重复）
  ③ 流通市值：每只标的 >50亿（排除小盘妖股）
  ④ 量比：每只当日量比 1.3–2.0倍（温和放量，非爆量）
  ⑤ 涨幅：每只当日涨幅 +1% ~ +3%（小阳，非涨停）
  ⑥ 时间窗：同日触发，或3个交易日内先后触发

板块状态（附加过滤）：
  该概念当日板块涨幅 <2%（尚未发酵）
  → 如果板块已涨>2%，即使组内标的满足条件，信号作废

排除条件（任一触发则整组作废）：
  组内任一标的若为连板股（连续2日涨停）
  OR 近10日涨幅 >20%
  → 该组信号作废

假设：该"群体建仓指纹"出现后，组内标的未来5-10日有超额收益。
```
