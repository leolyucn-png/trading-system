## 零、因果凭证令（2026-07-21 15:26 生效 · 优先级最高·凌驾一切）

```
任何候选的推荐理由,必须是入场前可观察的左侧证据。

合法句式（唯一）：
  "X事件已发生(凭证),价格尚未反应(数据),故埋伏。"
  凭证=催化+日期+出处 / 资金多日累计 / 筹码数据

三类永久禁止句式（出现一次→该候选自动作废+记第五节）：
  ❌ "因为它在涨"
  ❌ "因为板块强"
  ❌ "预计要涨停"

适用：所有模型（诸葛亮/关羽/刘备/刘彻/孙权/汉武帝）
      所有渠道（实时推荐/深扫报告/执行卡/独立分析）
```

## 一、信号登记三选一(无第四种)

```
每次推荐必须先标:
  ✅ 合格实盘:    催化具体可查证有日期 + 关羽通过 + 14:30
  📄 合格纸面:    同上, 但未实际买入(虚拟成交)
  ⚠️ 不合格纸面对照: 催化不合格·仅登记观察
  🚫 违规:       不合格催化却用了真钱 → 算事故

不合格催化= "军工时序""板块轮动""景气度"等非具体事件
关羽盲区+催化不合格 → 不得实盘
```
