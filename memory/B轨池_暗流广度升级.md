# B轨池 · 暗流广度升级（2026-07-17生效）

> **来源：** 外部文档#2金子部分 · 龙虾处置令三项
> **规则：** 文档中的案例、胜率、盈亏比数字一律标注"不可验证，不作依据"

---

## 升级内容

现行暗流池（关羽线4）逐条目新增 **广度确认** 标注列：

- **"单票暗流"** — 仅单只标的资金异动，无同概念群体验证
- **"广度确认(板块名)"** — 同概念≥3只、不同细分环节、同步温和放量

**过堂顺序：** 广度确认者优先级高于单票暗流，排序前置。
**此为排序规则，非放行标准** — 三问照过，不因广度确认免审。

## 广度确认判定方法

```
Step 1: 识别概念板块
  暗流表中"概念"列 → 确定所属一级概念板块

Step 2: 扫同概念标的（已安装数据源）
  调取该概念板块内，当日量比>1.3且涨幅+1%~+3%的标的
  检查是否≥3只、分属不同细分环节
  排除连板股/近10日>20%

Step 3: 标记广度
  ≥3只+不同环节+无排除 → 🟢 广度确认(板块名)
  满足部分但不全 → 🟡 疑似广度(需人工复核)  
  仅单只 → 🟡 单票暗流

Step 4: 排序
  广度确认 → 前置过堂
  疑似广度 → 中置
  单票暗流 → 后置
```
