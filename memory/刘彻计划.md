### 补丁①：板块全覆盖（核心！）
```diff
! 旧: 板块池 = 手工白名单 {军工,半导体,新能源,机器人,基建,材料}
! 问题: 游戏/传媒/消费/医药等=根本不扫描→信号全漏

### 模式检测器（启动第一优先级，先于所有策略）

```
启动刘彻 → 模式检测器 → 判定当前模式 → 决定用哪些策略

四模式判定：

🟢 主线持续模式：
  信号：科创50/创业板持续领涨
       主线板块成交集中度>30%
       主线板块连涨≥5天但未崩
  适用策略：A预埋伏 / C隔夜蓄力 / E深V确认 / D隔夜映射
  禁用策略：策略B（高潮日不追高）

🟡 高低切换模式：
  信号：主线板块资金连续3日流出
       低位板块连续资金流入+缩量涨
       市场成交前5%个股占比下降>10%
  适用策略：D政策预埋伏（提前2天）
  禁用策略：A/C（依赖原主线动量，已失效）
  
🔴 弱势震荡模式：
  信号：上证连续3日在窄幅区间
       成交额持续萎缩
       无连续领涨板块
  适用策略：C隔夜蓄力（窄幅版）+ 只做尾盘
  禁用策略：B/C（早盘版开路）
  
💀 系统性风险：
  信号：上证单日跌>2%
       恐慌指数飙升
       北向单日流出>50亿
  适用策略：全关，只观察
```

### 模式判定算法

```
步骤1：取过去3日数据
  ① 主线板块（30日涨幅第一）近3日资金流向
  ② 低位板块（30日跌幅第一）近3日资金流向
  ③ 全市场成交集中度（前5%个股成交占比）

步骤2：判定
  IF 主线资金连续流出≥3日 AND 低位连续流入≥3日
     → 🟡 高低切换模式
  ELSE IF 科创50连续领涨≥3日 AND 集中度>30%
     → 🟢 主线持续模式
  ELSE IF 上证3日波动<2% AND 成交萎缩
     → 🔴 弱势震荡模式
  ELSE IF 上证单日跌>2% AND 恐慌飙升
     → 💀 系统性风险

步骤3：输出
  当前模式：____
  适用策略：____
  禁用策略：____
  仓位上限：____
```
