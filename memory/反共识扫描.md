# 反共识扫描日志

> 建立：2026-06-10
> 目的：每次启动汉武帝时强制执行，扫描全市场非半导体/非共识板块的异动标的
> 规则：大家都看到的 = 大坑。没人看的 = 潜在alpha。

---

## 扫描框架

```
每次盘前扫描以下维度：

① 非半导体强势板块（不为画地为牢）
   □ 低空经济/飞行汽车
   □ 化工/新材料
   □ 军工/央企重组
   □ 新能源/储能
   □ 消费/医药
   □ 金融/地产

② 每个板块的龙头（真龙头，非跟风）
   □ 今日涨停板
   □ 连续涨停的标的
   □ 量比>5的非半导体标的

③ 反共识检查
   □ 今天所有人都盯着半导体？ → 那别的地方更有机会
   □ 有什么板块连涨3天却没人在讨论？
   □ 有什么票放量上涨但没有新闻覆盖？
```
