## 三、旭光涨停模式解剖

### 模式图：涨停→回调→再涨停

```
涨停① 5/27 → 跌到22.22 → 修复4天 → 
涨停② 6/4  → 跌到23.76 → 修复3天 →
涨停③ 6/11 → 回调28.69 → 等1天 →
涨停④ 6/15 → 一字板34.72 → 
涨停⑤ 6/16 → 一字板38.19 →
涨停⑥ 6/18 → 42.01

每次涨停后必回调3-7%，然后下一个涨停
回调幅度：5-7%，不破关键支撑
修复速度：3-5天
```

### 核心规律

```
① 涨停次日 ≠ 连板，而是回调
   → 不能追涨停当天，等次日回调买

② 回调幅度 5-7%
   → 跌到前涨停价的 -5% 处 = 买入窗口

③ 回调底部特征：低点不再被刷新 + 外盘>内盘
   → 6/8 跌到23.76 但外>内 ≈ 有人在吸

④ 修复节奏：3-5天一个完整循环
   → 涨停→跌3天→涨2天→再涨停

⑤ 连板启动信号：一字板出现
   → 6/15一字板 = 加速信号 → 后面连续涨停
```

## 五、学到的经验

### 经验1：独立走强票的"回调是买点"

```
特征：
  ① 涨停后不追，等回调3-5%
  ② 回调到前涨停价的-5% = 买点
  ③ 从低点算修复3-5天 = 第二个涨停
  ④ 如果出现一字板 → 加速信号 → 持有不动
```

### 经验2：恐慌日是送钱日

```
6/8 跌到23.76：
  当时恐慌的人：清仓 → 锁定亏损
  有经验的人：持有 → 等到42 → +76%
  聪明的人：加仓 → 翻倍

每次涨停后第二天暴跌 → 不是出货，是洗盘
跌的是散户的耐心，不是主力跑了
```

### 经验3：一字板启动后不要卖

```
6/15 一字板31.56 → 6/16一字板34.72 → 6/18 42.01
一字板 = 主力不给你买的机会 = 后面还有

教训：涨停当天可以不卖，等次日溢价
     一字板启动后 → 持有不动，不问价格
```
