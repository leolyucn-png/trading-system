## 一、系统定位

```
三大短线系统管"买什么"（战术）
秦始皇管"配多少、什么时候收"（战略）

核心：
  ① 宏观判断：大盘环境、板块轮动大方向
  ② 资金配置：钱应该放在哪个赛道、配置比例
  ③ 仓位管理：什么时候该重仓、什么时候该轻仓
  ④ 风险控制：识别系统性风险和板块性风险
```

## 二、核心原则

### 原则1：钱要在主线上

```
市场热点在哪，钱就要在哪。
不要在冷门票上重仓。

错误案例（6/17分水岭）：
  完美世界（游戏/传媒）= 冷门板块
  仓位34% ❌ 冷门票重仓
  结果：亏-16.7%，拖累总账户-7,371

正确做法：
  主线上仓位 ≥ 70%
  冷门票仓位 ≤ 10%
```

### 原则2：不要用赚热点的钱补冷门的窟窿

```
错误模式：
  热门票赚了+5%（+1,000）
  冷门票亏了-5%（-1,500）
  总账：亏500

  这是仓位配错的必然结果。
  赚的票仓位小，亏的票仓位大 → 总账永远亏。
```

### 原则3：大盘环境决定仓位上限

```
🟢 牛市/主线明确 → 仓位80-100%
🟡 震荡/分化 → 仓位30-50%
🔴 调整/恐慌 → 仓位10-20%
💀 股灾/系统性风险 → 空仓

当前(6/23)：创业板-4.09% → 🔴 调整/恐慌
  应配仓位：10-20%
  实际仓位：73% ❌ 严重超标
```

### 原则4：胜率 vs 赔率

```
短线交易的期望值 = 胜率 × 赔率

正确模式：
  高胜率(>60%) + 高赔率(>1:2) = 赚钱
  低胜率(<40%) + 高赔率(>1:3) = 赚大钱

错误模式：
  高胜率(>60%) + 低赔率(<1:1) = 不赚钱
  低胜率(<40%) + 低赔率(<1:1) = 亏钱
```

## 🆕 2026-06-29 新增：板块拥挤度检测（每日启动必做）

### 拥挤度=板块见顶预警
```
核心逻辑：当一个板块的成交额占比达到极端值时=抱团极致=高低切即将发生
历史验证：2007/2015/2021三次崩盘前，前5%个股成交占比均>40%
```

### 每日扫描输出格式（5分钟）
```
📊 板块拥挤度扫描 [日期]

成交集中度：全市场前5%个股占总成交比 = ____%（警戒线40%）

板块监测：
| 板块 | 3日资金 | 5日涨幅 | 拥挤判定 |
|:----|:-------:|:-------:|:--------|
| 半导体 | ±XX亿 | +XX% | 🔴拥挤/🟡正常/🟢冷门 |
| 创新药 | ±XX亿 | +XX% | 🔴拥挤/🟡正常/🟢冷门 |
| ... | | | |

连涨≥5日板块：＿＿（警惕高潮）
连跌≥3日板块：＿＿（关注轮动）

⚠️ 拥挤度预警板块：＿＿（不允许追高）
💡 冷门关注板块：＿＿（可埋伏轮动）

结论：当前资金方向 ________ | 明天可能轮到 ________
```

### 拥挤度判定标准
```
判定维度：
  ① 板块成交额占全市场比（>20%=拥挤，>30%=过热）
  ② 板块5日涨幅（>15%=拥挤，>25%=过热）
  ③ 板块内涨停家数/上涨家数比（>30%=涨停潮=高潮）
  ④ 板块ETF溢价率（>3%=情绪极致）

拥挤度>70% → 🚨 不可追高，只出不进
拥挤度>85% → 🔴 强制减仓该板块所有持仓
```

### 资金流向全景图
```
每日启动强制跑：
  💰 近3日资金净流入TOP5：＿＿＿ ＿＿＿ ＿＿＿ ＿＿＿ ＿＿＿
  💵 近3日资金净流出TOP5：＿＿＿ ＿＿＿ ＿＿＿ ＿＿＿ ＿＿＿
  ⚠️ 连续流入≥3日（蓄力中）：＿＿
  🔴 连续流出≥3日（撤退中）：＿＿
```

## 三、每日执行

### 收盘后宏观检查

```
□ 大盘环境评估（GATE 0级别）
□ 当前主线板块是什么
□ 主线板块处于什么阶段（启动/主升/高潮/退潮）
□ 板块拥挤度扫描（新增）
□ 我的仓位是否符合当前环境
□ 我的持仓是否在主线上
```

### 仓位置换规则

```
当冷门票亏损 > 10%时：
  → 自动检查：它为什么亏？
  → 如果是因为板块冷门 → 减仓50%
  → 如果是因为大盘系统性风险 → 减仓70%
  → 如果是因为个股基本面问题 → 清仓

当热门票盈利 > 10%时：
  → 设置移动止盈（从最高点回落5%就卖）
  → 不轻易卖飞
```

## 🆕 2026-06-30 新增：板块内部原子化诊断（用户亲授）

> 只判断板块拥挤度不够。同一板块内，不同个股的资金态度可能完全不同。
> 必须原子化扫描板块内部的个股表现差异，才能准确判断板块是真涨还是假涨。

### 板块内部分化三类型

#### 类型1：健康齐涨型
```
特征：板块涨2-3%，板块内80%个股同步上涨±1%
含义：资金均匀买入，板块行情真实
操作：✅ 可参与，选龙头效率最高

案例：军工 2026-06-30
  军工ETF+2.92%，海特+2.87%，振华+2.29%，钢研+2.75%
  多数票同步 → 健康齐涨
```

#### 类型2：先锋分化型
```
特征：板块涨1-2%，但个别股票暴涨+10%以上，多数票平盘或微跌
含义：资金在突击式买入个别标的（可能有未公开利好），
      但板块整体尚未形成共识
操作：🟡 需判断先锋是真龙还是消息炒作
      龙头如果次日继续强→板块可能扩散
      龙头如果一日游→板块不动

案例：光伏 2026-06-30
  光伏ETF+2.09%，但东方日升+13%，捷佳伟创+7%
  其他票(阳光电源-1%)没跟 → 先锋分化型
```

#### 类型3：虚假繁荣型（最危险）
```
特征：板块涨，但仅靠1-2只权重股拉升
      板块内80%个股下跌或平盘
含义：资金在拉权重掩护出货
操作：❌ 不参与，板块是假的

判别方法：
  查看板块内涨跌家数比
  如果涨的家数远少于跌的家数但板块指数是红的
  → 虚假繁荣
```

### 联动张飞判别
```
秦始皇产出板块内部分析后 → 传递给张飞
张飞叠加个股三情况判别（A资金不喜欢/B套牢盘/C还没轮到）
→ 双重验证后的结论更可靠

例：光伏 2026-06-30
  秦始皇判定：先锋分化型（东方日升爆拉+13%，多数没跟）
  张飞对阳光电源判定：A资金不喜欢（-1.05%，量比<1）
  → 综合结论：光伏有先锋但还没扩散，龙头没动=仍需观望
```

### T+1特殊仓位规则（2026-06-30新增）

> 秦始皇仓位管理主要针对中长期持仓。T+1过夜仓的仓位判定标准不同。

```
T+1过夜仓（次日10:30前必卖）：
  □ 单只仓位可到30%（比中长期15%高一倍）
  □ 原因：只持有一天，风险暴露时间短
  □ 但总量不超过总资金的40%
  □ GATE 0红灯时仍强制禁止一切T+1开仓

适用场景：刘彻策略D-隔夜映射、策略A-尾盘埋伏
```
