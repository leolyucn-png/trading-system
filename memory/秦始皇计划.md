## 一、系统定位

```
运行层级（强制顺序）:

  🏛️ 秦始皇(第0层) → 🗡️ 张飞 → 🏯 关羽 → 🐉 刘备
  → 🐉 刘彻 / 🏯 诸葛亮 / 🦁 汉武帝

铁律:
  所有模型启动前, 必须先读秦始皇评分
  秦始皇评分 < 40 → 全链路自动关闭
  秦始皇评分 < 50 → 仓位上限2只
```

### 核心原则

```
① 秦始皇不预测涨跌, 只评估风险
② 秦始皇是刹车, 不是油门
③ 秦始皇的评分 = 所有模型的上限约束
④ 秦始皇错了 → 停用比亏损好
```

## 二、工作流程

### 每日运行时间

| 时间 | 事件 | 用途 |
|:----|:----|:----|
| 08:50 | 开盘前首次评分 | 决定今日仓位上限 |
| 10:00 | 盘中修正 | 验证开盘方向 |
| 13:00 | 下午开盘评分 | 应对中午变化 |
| 15:10 | 收盘评分 | 记录当日风险状态 |
| 21:00 | 次日预判 | 基于收盘+US市场预判明日 |

### 执行流程

```
08:50 启动秦始皇
  ↓
① 拉取最新大盘数据（Sina/腾讯实时）
② 四维评分计算
③ 输出评分+仓位上限
④ 写入秦始皇日志
  ↓
    如果评分 < 40 → 输出"禁止新开仓"
    如果评分 < 50 → 输出"上限2只"
    如果评分 ≥ 80 → 输出"可满仓"
  ↓
刘彻/诸葛亮/汉武帝等依赖模型读取评分
  ↓
汉武帝执行前检查:
  IF 评分 < 40 AND 指令为"买入" → 否决
  IF 评分 < 50 AND 新开仓数 ≥ 2 → 否决
```

## 三、四维评分体系（总分100）

### 维度1：趋势判定（40分）

| 子项 | 分值 | 数据源 | 判定标准 |
|:----|:---:|:------|:--------|
| 上证vs20日线 | ±15 | Sina指数 | 线上+15, 线下-15, 接近0 |
| 科创50vs上证 | ±10 | Sina指数 | 科创强于上证+10, 弱于-10 |
| 大盘量能 | ±10 | 腾讯量比 | 5日均量比>1.2+5, <0.8-5 |
| 5日趋势 | ±5 | 5日K线 | >+2%+5, >-2%-5 |

### 维度2：市场广度（25分）

| 子项 | 分值 | 数据源 | 判定标准 |
|:----|:---:|:------|:--------|
| ETF涨跌比 | ±10 | 38ETF扫描 | >60%红+10, <30%红-10 |
| 涨停/跌停比 | ±8 | 涨停板 | >3:1+8, <1:3-8 |
| 板块结构 | ±7 | 关平赛道 | 健康齐涨+7, 虚假繁荣-7 |

### 维度3：资金流向（20分）

| 子项 | 分值 | 数据源 | 判定标准 |
|:----|:---:|:------|:--------|
| 板块持续性 | ±8 | 关羽线4 | 有持续流入板块+8, 无-8 |
| 两融余额 | ±6 | 融资数据 | 上升+6, 下降-6 |
| 北向资金 | ±6 | AkShare | 净流入+6, 净流出-6 |

### 维度4：风险信号（15分，扣分制）

| 触发条件 | 扣分 | 说明 |
|:--------|:---:|:-----|
| 科创/创业板单日跌>5% | -10 | 恐慌信号 |
| 跌停>30家 | -10 | 系统性风险 |
| 北向单日流出>50亿 | -8 | 外资出逃 |
| 板块拥挤>70% | -5 | 追高风险 |
| 连续3日下跌 | -5 | 趋势恶化 |

## 四、评分与仓位上限

```
≥80分 → 🟢 健康市场 → 可满仓（上限6只）
        个股逻辑有效，正常操作

60-79分 → 🟡 温和市场 → 适度交易（上限3只）
        个股逻辑大部分有效，控制仓位

40-59分 → 🔴 弱势市场 → 低仓位（上限2只）
        个股逻辑开始失效，以卖出为主

<40分  → 💀 危险市场 → 禁止新开仓
        只处理旧仓位，不买任何新票
```

## 五、参考读数（v2.2新增 · 背景信息不计分）

> **设计定位：** 两个读数**只入评分背景**，不单独构成信号，不改变红黄绿规则。
> 它们是给模型和用户的「环境热力图」，不是加减分项。

### 读数A：全市场广度

#### 子项① 当日上涨家数占比

| 字段 | 内容 |
|:----|:------|
| 用途 | 判断当日是普涨还是少数权重股护盘 |
| 数据源 | 腾讯/Sina全A股行情API → 提取所有非ST非退市股票→计数涨跌家数 |
| 算法 | `上涨家数 / (上涨家数+下跌家数+平盘家数) × 100%` |
| 刷新频率 | 每交易日盘后(15:00) |
| 参考含义 | >70%=普涨健康 / 50-70%=分化 / 30-50%=弱势 / <30%=全面崩溃 |
| ⚠️ 禁止 | 此读数不进入四维评分公式，不转化成分值 |

#### 子项② 创60日新低家数

| 字段 | 内容 |
|:----|:------|
| 用途 | 量化下跌的广度——是否大面积破位 |
| 数据源 | 腾讯/Sina全A股行情API → 遍历所有非ST非退市股票的60日最低价历史 |
| 算法 | `当日最低价 < 过去60日最低价` 的股票数量 |
| 刷新频率 | 每交易日盘后(15:00) |
| 参考含义 | <50只=正常 / 50-200只=弱势 / 200-500只=深度调整 / >500只=系统性风险 |
| ⚠️ 禁止 | 此读数不进入四维评分公式，不转化成分值 |

### 读数B：估值分位

| 字段 | 内容 |
|:----|:------|
| 用途 | 判断当前位置的历史估值水位 |
| 数据源 | AkShare `stock_a_pe` 或万得全A等权PE历史数据（本地缓存） |
| 指标 | 全A等权PE历史百分位（非市值加权，等权PE对中小市值更敏感） |
| 刷新频率 | **月更**（月底收盘后更新一次，月中不变） |
| 参考含义 | <20%=低估区 / 20-50%=中等 / 50-80%=偏贵 / >80%=历史高位 |
| 缓存文件 | `memory/cache/all_a_equal_weight_pe_percentile.txt`（月更，存最新百分位+更新日期） |
| ⚠️ 禁止 | 此读数不进入四维评分公式，不转化成分值；月更频率杜绝日内噪音 |

### 参考读数的用法（仅以下3种，不得扩展）

```
用法1：出现在秦始皇输出模板的「参考读数」区，供用户阅览

用法2：出现在开盘前评分的衡量判断文字中（不转化成分值）
  例："全市场广度偏低(上涨占比32%)，但估值分位在历史低位(15%)，
      当前位置属于'便宜但没人买'的磨底阶段"
  但：不允许"广度低→扣分"，不允许"估值低→加分"

用法3：所有模型(关羽/刘彻/张飞/诸葛亮/汉武帝)可以读取
  但：只能作为定性描述的背景注脚，不能作为评分/过滤/门槛依据
```

## 八、附则

### 秦始皇说真话原则

```
① 秦始皇不为了"好看"调分
   今天给-20分就是-20分，不因为"可能有反弹"就加分
② 秦始皇可以错
   但错的方向是"过度保守"，不是"过度激进"
   给-20分实际市场反弹了 → 安全
   给+80分实际市场崩了 → 危险
③ 所有模型都必须尊重秦始皇的评分
   可以不执行(用户决定)，不能不知道
```
