### 5.2 波动耐力检查（新增 2026-06-30 用户亲授）

> **问题：诸葛亮选出来的票DNA都合格，但持有期间-20%~-30%的回撤，人扛不住。**
> 埃斯顿、康强电子、航发科技三只涨停票，全都在回撤中被洗出去了。
> **不是票选错了，是仓位和波动不匹配。**

#### 候选分级制度（波动性决定仓位）

```
入池前必须计算：近3个月最大回撤幅度

回撤 < 15%（低波动） → 活跃池 ✅  仓位上限20%
回撤 15-25%（中波动） → 验证池 🟡  仓位上限10%
回撤 > 25%（高波动） → 观察池 🔵  不买，只跟踪

原因：波动越大，人越拿不住。
     拿不住的好票 = 等于没买。
```

#### 仓位计算公式
```
建议仓位 = 账户总资金 × (1 - 近3月最大回撤率/100) × 30%

例：预期回撤20%的票
  仓位 = 总资金 × (1 - 20/100) × 30% = 总资金 × 24%
  但分级限制：中波动≤10%
  → 取两者最小：10%

硬性上限：分级仓位 < 公式仓位时，取分级仓位的值
```

#### 已入库案例
```
埃斯顿 002747：
  pre-启动回撤约25% → 观察池（不买）
  如果当时按此规则 → 小仓位持有或等回撤缩小→不会被洗

康强电子 002119：
  回撤约25% → 观察池
  同理

航发科技 600391：
  今日涨停但成本36.85现价33.45还亏-9%
  回撤幅度约-20% → 验证池 ≤10%
  如果当时只配10%仓位 → 今天亏不到总账户的1%
  → 就能拿住
```

#### 联动秦始皇
```
候选分级结果同步给秦始皇：
  低波动→正常仓位
  中波动→仓位减半
  高波动→不配置
```
