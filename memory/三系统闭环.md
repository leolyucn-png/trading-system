## 二、每个节点的产出

### 节点①：诸葛亮出情报

```
产出格式：
  GATE 0: 🟢绿灯/🟡黄灯/🔴红灯
  主线：XXX
  候选：活跃池(新推荐) + 验证池(老票机会)
  风险：XXX
```

### 节点②：秦始皇验证

```
产出格式：
  票名：XXX
  GATE 1-5：通过/不通过
  结论：✅ 通过 / ❌ 打回
  打回原因：XXX
```

### 节点③：汉武帝执行 + 接棒判断

```
产出格式：
  操作：买入/卖出
  盈亏：+/-XXX元
  接棒判断：
    ① 赚钱了？ ✅/❌
    ② 逻辑还在？ ✅/❌
    ③ 基本面干净？ ✅/❌
  结果：转诸葛亮 / 归档
```

### 节点④：诸葛亮长期监控

```
产出格式（每日一次）：
  验证池状态：
    🥇 旭光电子：现价31.56 | 距再入区间28-30还有+5%
    🥇 天风证券：现价3.29 | 距再入区间3.10-3.15还有+5%
    🥇 中国稀土：现价55.32 | 距再入区间53-54还有+2.5%
  
  再入提醒：无/有（XX票回调到位）
```

## 三、闭环的好处

```
旧系统（开环）：
  诸葛选→汉武做→赚钱→清仓→下一只→不管了
  → 好票丢了，坏票下次还选

新系统（闭环）：
  诸葛选→汉武做→赚钱→逻辑还在？→诸葛接着看
  → 回调到位→汉武再做→循环
  → 好票反复吃，坏票自动淘汰
```

### 旭光在这个闭环里的完整路径

```
① 诸葛选：6月初 可控核聚变概念
② 汉武做：6/8-6/12持有穿越 ✅ 赚钱了
③ 接棒检查：逻辑还在（核聚变论坛本周）✅
④ 转诸葛：进入验证池
⑤ 诸葛盯：6/15又涨停 → 等回调28-30
⑥ 回调到28-30 → 通知汉武
⑦ 汉武再进 → 再赚一次
⑧ 循环
```

## 四、执行规则

```
启动条件：
  每次session启动 → 三系统必须全部加载
  诸葛亮必须先跑情报 → 再给汉武帝
  秦始皇必须在交易前跑完五道门

输出要求：
  任何分析必须标注是哪个节点的产出
  格式：[节点①/②/③/④] + 内容

归档规则：
  赚钱+逻辑不在 → 写入经验教训库（成功案例）
  亏钱+逻辑不在 → 写入经验教训库（失败案例）
  亏钱+逻辑还在 → 写入经验教训库（模式识别错误→修正）
```
