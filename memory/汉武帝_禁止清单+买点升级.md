## A. 尾盘买点升级（来自模式2·趋势回踩）

原汉武帝买点: 14:30尾盘窗口，不追高、不抢跑。
新增量化确认条件：

```
尾盘14:30确认清单（满足3项中≥2项 → 执行）:
  □ 股价回踩20/30日均线（距均线±3%以内）
  □ 当日成交量缩至5日均量的60%以下
  □ 当日收小阳/十字星（日涨跌在-1%到+3%之间）
```

> 原模式28（涨幅>3%分阶段判定）保持不变。此为新增强确认条件。
