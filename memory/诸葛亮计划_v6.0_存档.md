## 🎯 核心定位 v6.0

```
旧定位（v5.0已废除）：
  先找主线板块 → 再从板块里找票 → 选概念跟风
  → 结果：航运(crash)/黄金(不动)/稀土(跟大宗)/天风(跟券商)
  → 全是外驱票，没有独立走强能力

新定位（v6.0）：
  找有"独立走强DNA"的票 → 再验证板块和逻辑
  → 目标：旭光式的——逆势抗跌、放量异动、资金异常
  → 特征：内驱>外驱，自身力量>板块风口
```

### 旭光为什么是榜样

```
6/8 大盘跌-1.8%  → 旭光被误杀-7.2%（但低位有大额买盘）
6/9-6/10 修复期  → 旭光独立反弹，不跟大盘节奏
6/11 大盘-0.5%   → 旭光独立涨停+9.99%（第一次证明）
6/15 大盘+1.6%   → 旭光又涨停（第二次确认）
6/16 竞价         → 旭光又涨停，封单18.8万手（第三次，已成定局）
                               ↓
累计46%涨幅，而且是我们自己持仓发现的，不是看新闻找的
```

**旭光不是靠板块逻辑选出来的——是靠盘面信号找到的，验证了逻辑再确认的。**

## 🗂️ 候选池迭代机制

### 更新规则

```
每周一：全量重建（基于周末消息+本周资金流向）
每周三：半量更新（剔除前3天跑输的，替换新发现）
每周五：全面评估（确定下周保留什么）

单票最低持仓周期：3天（给催化剂发酵时间）
单票最高持仓周期：10天（过了还不涨=判断错了）
```

### 评分标准

> 简化版：不再搞复杂的加权评分，改用"通过/不通过"检查

| 检查项 | 分值 | 通过条件 |
|:-------|:---:|:---------|
| 在主线上 | 必过 | 属于第2步判断的主线/次线板块 |
| 有催化剂 | 必过 | 本周内有可预期的利好事件 |
| 涨幅合理 | 加分 | 今天涨幅0-5%（没跑太多） |
| 有量 | 加分 | 今日成交量>20日均量 |
| 收盘健康 | 加分 | 收盘在今日高点的-2%以内 |
| 非负面 | 必过 | 无减持/问询/ST |

**3项必过全部通过 + 至少2项加分 = 候选**

## 🔄 汉武帝→诸葛亮接棒机制（新增）

> **定位：打通短线与长期的断点。**
> 汉武帝赚完短线利润后，如果票的逻辑还在，转交给诸葛亮继续跟踪。

### 为什么要接棒

旭光电子案例：
```
汉武帝：6/8→6/12持有穿越，验证了是好票
      6/12卖出后 → 不再跟踪
诸葛亮：6/15旭光又涨停 → 完全不知道
      → 没人告诉诸葛亮"这个票验证过了"

结果：好票断了，再也没人管它
```

### 接棒触发条件

汉武帝每次清仓后，自动判断：

```
① 这笔交易赚钱了吗？
   ├─ 赚了 → 票的赚钱能力已验证 → 考虑转
   └─ 亏了 → 逻辑可能有问题 → 不转

② 当初买入的逻辑还在吗？
   ├─ 还在（概念没变/政策没变/行业趋势没变）→ 转
   └─ 没了（催化兑现/逻辑被证伪）→ 不转

③ 票的基本面有问题吗？
   ├─ 无减持/无问询/无ST → 转
   └─ 有负面 → 不转

三条件都满足 → 正式转接给诸葛亮
任何一条不满足 → 归档，不转
```

### 旭光DNA清单（找下一只旭光的标准）

```
🔴 必要特征（缺一不可）：
  □ 逆势抗跌 — 大盘跌它不跌，或跌了能独立修复
  □ 资金异常 — 放量时有大额买盘，不是散户冲的
  □ 自身逻辑 — 有独立的催化剂，不是"板块涨它跟"
  □ 非跟风 — 板块不涨它能涨，板块涨它能涨停

🟢 加分特征：
  □ 低位启动 — 不是高位接盘
  □ 多波次潜力 — 首板后有整理再涨可能
  □ 基本面干净 — 无减持/问询/ST
  □ 有"故事" — 资金能讲得出逻辑（核聚变/AI/机器人等新故事）
