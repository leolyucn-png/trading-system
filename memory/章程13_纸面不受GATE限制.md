# 🆕 章程⑬ — 纸面不受GATE限制

> 2026-07-13 17:19 签署生效

## 规则

- 🔴 **实盘**：照禁。红灯不买，黄灯≤60%，底线不破。
- 🟢 **纸面**：不受限。每日八步流程正常产出候选。
  - 过了3-5步、卡在GATE或催化不足的 → 登记为纸面仓
  - 虚拟成交（模拟买入价/数量）→ 正常跟踪 → 虚拟出场
  - 目标：累计**50笔对照组**

## 原理

> 系统在不能开枪的日子里也要保持满速打靶。
> 纸面仓是验证引擎的燃料——等红灯解除时，手里已经有50份实测报告。

## 对照组意义

| 维度 | 实盘 | 纸面仓 |
|:----|:----|:------|
| 选股逻辑 | 完全相同 | 完全相同 |
| 买入点 | 受GATE限制 | 按信号最优时机 |
| 持有周期 | 相同 | 相同 |
| 出场规则 | 相同 | 相同 |
| 对比 | → | 验证：如果GATE没拦着，这笔会赚还是亏？ |
