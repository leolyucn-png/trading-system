## 1. 分布均匀性评估

### 1.1 四种类型的期望分布

| 类型 | 报告占比 | 假设等均匀分布 |
|:----|:--------:|:------------:|
| Game-Marker | 51.6% (~318) | 25% |
| Casual-Player | 20.5% (~126) | 25% |
| Filter-Seeker | 18.0% (~111) | 25% |
| Palms-Joined | 9.9% (~61) | 25% |

**判断：极度不均匀。** Game-Marker 占过半，而 Palms-Joined 仅 9.9%。

### 1.2 卡方拟合优度检验

```
H₀: 四种类型在总体中均匀分布
χ² = Σ((O-E)²/E)，df = 3

假设 n=616，E=154每类
0: (318-154)²/154 = 174.5
C: (126-154)²/154 = 5.1
F: (111-154)²/154 = 12.0
P: (61-154)²/154 = 56.2

χ² ≈ 247.8, df=3
p < 0.00001
```

**结论：极显著偏离均匀分布**（χ²≈247.8, p<0.00001），但这本身不是方法缺陷——这恰恰是核心发现。问题是：这种不均匀性被作为"类型学"呈现，但如果Palms-Joined只有61个样本($n$≈61)，该类型中进一步拆分子类别或做亚组分析的统计力严重不足。

### 1.3 最小类型样本力分析

Palms-Joined 仅有 ~61 张图片。在 13 维度编码 + 遗址类型交叉分类后，每个维度-遗址单元格的理论频数可能在 1-5 之间，卡方检验的合理性存疑。

## 2. Game-Marker 51.6% vs Palms-Joined 9.9% — 比例差异显著性检验

### 2.1 双比例z检验

```
p₁ = 0.516（318/616）
p₂ = 0.099（61/616）
p_pooled = (318+61)/(2×616) = 379/1232 = 0.308

SE = sqrt( p_pooled × (1-p_pooled) × (1/616 + 1/616) )
   = sqrt( 0.308 × 0.692 × 0.00325 )
   = sqrt( 0.000692 )
   ≈ 0.0263

z = (0.516 - 0.099) / 0.0263 = 0.417 / 0.0263 ≈ 15.85
p < 0.00001
```

**结论：统计极其显著（z≈15.9, p<0.00001）**。差距巨大，不是抽样波动。

### 2.2 效应量

Cohen's h = 2×arcsin(√p₁) − 2×arcsin(√p₂)
- arcsin(√0.516) = arcsin(0.718) = 0.799
- arcsin(√0.099) = arcsin(0.315) = 0.321
- h = 2×(0.799 - 0.321) = 0.956

**效应量 h = 0.956**，属于"非常大"（阈值：小=0.2，中=0.5，大=0.8）。

### 2.3 方法论注意点

> ⚠️ 这一差异明确存在，无需统计检验也能看清。论文公开这个比例差异时，**真正需要回答的不是"是否显著"（当然显著），而是"这个分布反映了真实世界还是编码偏差"**——是否因为 Palms-Joined 姿态更难在打卡场景中捕捉（合十手通常短暂出现），而 Game-Marker 有更持久的视觉标记（手机/游戏UI/标志性手势）？

## 3. 合十图片中40%有游戏元素 → Confusion Matrix 分析

### 3.1 列联表重构

| | 有游戏元素 | 无游戏元素 | 合计 |
|:--|:---------:|:---------:|:---:|
| Palms-Joined | 24 (40%) | 37 (60%) | 61 |
| Non-Palms-Joined | 294 (53%) | 261 (47%) | 555 |
| 合计 | 318 | 298 | 616 |

*注：假设非合十类型中游戏元素的整体占比与Game-Marker占比相近的不严谨推算，更精确需论文原始数据*

### 3.2 奥兹比率 (Odds Ratio)

```
OR = (24/37) / (294/261) = 0.649 / 1.126 = 0.576
```

OR ≈ 0.58，意味着 Palms-Joined 图片中出现游戏元素的**几率比非合十类型低约 42%**。这是负相关——合十姿势的人反而不太有游戏元素。

### 3.3 结构模式判断

40%的重叠率——这需要看**预期值**：
- 如果游戏元素在总体中占 p=51.6%，Palms-Joined 期望重叠率为 51.6%
- 实际观测为 40% → 低于期望约 11.6 个百分点

**判断：存在结构性模式，但不是随机噪音，而是有意义的负相关。** 即"合十"和"游戏元素"之间存在一定程度的互斥——真正虔诚的朝圣者（完全合十）与游戏导向的打卡者（展示游戏界面）在行为上偏向不相容。

### 3.4 四格表Fisher精确检验建议

由于Palms-Joined单元格较小（期望频数约31.5），应优先使用Fisher精确检验而非Pearson χ²：

```python
# 伪代码
from scipy.stats import fisher_exact
table = [[24, 37], [294, 261]]
odds_ratio, p_value = fisher_exact(table)
# 预期p < 0.05
```

## 4. 遗址类型 × 游戏元素关联（§4.4）→ 列联表分析评估

### 4.1 论文中的分析结构

从论文描述，§4.4 做了：
- 遗址类型（游戏内地点 vs 现实景点 vs 混合空间 等）× 游戏元素存在性
- 以及 × 朝圣者类型

### 4.2 列联表充足性问题

| 问题 | 评估 |
|:----|:-----|
| 66个遗址，如果按5种类型分 | 每类约13个，但具体分布未知 |
| 最小期望频数 | 若某些类型×游戏元素的单元格期望 < 5，Pearson χ² 不可靠 |
| 多重比较 | 多次χ²检验（不同类型×不同维度）→ 未报告Bonferroni校正 |

**建议使用Fisher-Freeman-Halton精确检验**替代标准χ²检验，或至少报告每个单元格的期望频数。

### 4.3 Cramér's V 效应量

应报告每个关联的Cramér's V以判断效应量大小。如果遗址类型×游戏元素关联显著但V<0.1，则实际意义有限。

### 4.4 修正标准化残差

```python
# 识别哪些单元格对χ²贡献最大
# 标准化残差 = (O-E)/sqrt(E)
# |residual| > 2 表示该单元格显著偏离独立假设
```

论文未报告这个，但这对解释 §4.4 的发现至关重要——不能只说"总体显著"，要说是哪些特定单元格驱动了显著性。

## 5. 样本量 Power Analysis

### 5.1 总样本力：n=616 是否足够？

| 分析类型 | 样本量评估 | 备注 |
|:--------|:---------|:-----|
| 4类型整体描述（频率） | ✅ 充分 | 即使最小类n=61，比例估计SE=3.8% |
| 类型×维度交叉（13维） | ⚠️ 边界 | 13维×4类=52单元格，平均每单元格~11.8，但部分可能<n |
| 类型×遗址类型 | ❌ 不足 | 66遗址×4类型=264单元格，平均仅2.3/单元格 |
| 亚组分析（Palms-Joined子类） | ❌ 严重不足 | n=61，拆分子类后无可信统计 |

### 5.2 事后Power计算

```
对于χ²检验（df=3, α=0.05），
n=616 检测中等效应w=0.3 的power > 0.99
n=616 检测小效应w=0.1 的power ≈ 0.45

但在Palms-Joined子集（n=61）中：
检测中等效应w=0.3的power ≈ 0.37
检测小效应w=0.1的power < 0.10
```

**核心结论：** 总样本力看似充足，但真正有价值的问题（交叉分类、亚组比较）在Palms-Joined子集中统计力严重不足。

### 5.3 建议

若按G*Power建议，要达到"双比例检验，检测d=0.3的中等效应，α=0.05, power=0.80"：
- 最小组需要 **n=175/组** → 建议总样本至少 **700**
- Palms-Joined实际只有61 → 需要**将Palms-Joined数据扩至3倍当前规模**

## 6. 回归分析建议（Predicting Game-Element Presence）

### 6.1 数据结构

- 因变量（Y₁）：game_element_present (0/1) — 二分类
- 因变量（Y₂）：pilgrim_type (4类) — 多分类
- 自变量（X）：
  - Site type（遗址类型：游戏内/现实/混合/...）
  - Posture type（posture编码）
  - Group size（单人/多人）
  - Time/date（发布时间——如果有）
  - Number of elements（图片中元素丰富度）
  - Caption sentiment / hashtag count（如果有文本数据）

### 6.2 建议模型

#### 模型1：二元Logistic回归

```
logit(P(game_element=1)) = β₀ + β₁(site_type) + β₂(posture) + β₃(group_size) + ε
```

- 适合二分类因变量
- 可解读为Odds Ratio（OR）
- 需要检验多重共线性（VIF < 5）

#### 模型2：多项Logistic回归（Multinomial Logistic）

```
P(pilgrim_type = j) / P(pilgrim_type = reference) = Xβⱼ
```

- 以Game-Marker为参考类
- 识别哪些因素区分Palms-Joined与其他类型
- 小样本类（Palms-Joined）的参数估计可能不稳定

#### 模型3：混合效应模型（Mixed Effects）

```
logit(P(game_element=1)) = β₀ + β₁(posture) + (1|site_id) + (1|coder_id)
```

- 如果66个遗址可视为随机截距
- 如果多个编码器有交叉编码的图片
- **更适合本文结构**，因为图片在遗址层面存在聚类

### 6.3 严重约束

**n=616对回归分析来说不算大**，特别是有66个遗址聚类：
- 遗址层面的聚类效应会大幅降低有效样本量（Design Effect ≈ 1 + (m-1)×ρ）
- 如果组内相关系数 ICC=0.10，平均每个遗址m=9.3，则DE≈1.83
- 有效样本量降到 n_eff ≈ 616/1.83 ≈ 337

### 6.4 为什么不建议简单做线性回归（OLS）

- 因变量为二分类 → 违反OLS正态性假设
- 异方差性严重且不可通过转换校正
- 预测值可能超出[0,1]范围
- 必须用GLM框架
