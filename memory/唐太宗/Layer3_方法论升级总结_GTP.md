## 2. 三大核心缺口（相互嵌套）

### 缺口A：类型学的统计支撑不足

```
4种类型 ← 扎根理论分类
↓
Game-Marker 51.6% vs Palms-Joined 9.9%
↓
最小类n=61 → 交叉分析的统计力不足
↓
66遗址×4类型 → 262单元格，平均每单元格2.3个样本
↓
聚类效应未处理 → 有效样本量从616下降到~337
```

**症状：** 类型学的分类建构在理论上合理，但在统计验证层面缺乏系统支撑。

### 缺口B：编码方案的可复现性黑洞

```
扎根理论（质性）←→ 量化编码（量化）
↓
论文宣称扎根理论路径
↓
但未公布：初期代码列表、轴向编码的范式模型、选择编码的收敛决策路径
↓
同时未公布：每个编码维度的ICR kappa值
↓
总Kappa 0.82 → 可能掩盖某些维度的低一致性
```

**症状：** 论文处于"质性"与"量化"的灰色地带——质性的透明度不够，量化的严谨性不够。

### 缺口C：视觉数据的非视觉呈现悖论

```
研究问题：打卡朝圣者的视觉行为分类
数据：616张小红书图片（高密度视觉数据）
呈现手段：文字+百分比（低维度降维）
缺失：跨类型视觉拼贴、热力图、弦图等交互展示
```

**症状：** 视觉内容分析的论文却几乎是"无图论文"，核心发现藏于文本中。

## 4. 唐太宗v3.0 Layer 3 方法论升级启示

### 4.1 从本次审计中提炼的方法论原则

| 原则 | 描述 | 跨应用价值 |
|:----|:-----|:----------|
| **P1: 类型学验证的双重性** | 任何类型学（typology）必须有质性建构路径+量化验证证据，缺少任何一方都脆弱 | 适用于ESG评级类型学、用户画像分类 |
| **P2: 聚类效应的不可忽视** | 嵌套结构(nested data)中设聚类会导致严重假阳性 | 适用于所有多地点数字数据研究 |
| **P3: ICR的全维度报告义务** | 总kappa掩盖结构性问题，per-dimension是底线要求 | 适用于任何有编码多维度的内容分析 |
| **P4: 最小类别的统计透明度** | 任何分类研究中最小类别的样本量、power、效应量必须单独报告 | 适用于所有不平衡分类问题 |
| **P5: 视觉数据的不可降维呈现** | 质性视觉数据的核心发现应当通过视觉方式呈现 | 适用于社交媒体图像分析、视频分析 |

### 4.2 三层方法论诊断框架

```
Layer 1: 描述性 → "发现了什么"
  （GTP: 616张图→4类型→比例差异—当前基本做到）
  
Layer 2: 验证性 → "发现是否可信"
  （本审计的三技能任务：统计检验、可复现性、可视化透明度
   → 发现 layer 1 的结论需要更多支撑）

Layer 3: 规范性 → "发现为什么重要"
  （理论贡献：GTP在media pilgrimage/contents tourism/digital religion
   交叉处的位置 → diagram-maker建议的框架图）
```

**GTP论文当前状态：** Layer 1 扎实（✦✦✦✦✧），Layer 2 薄弱（✦✦✧✧✧），Layer 3 有潜力（✦✦✦✧✧）
