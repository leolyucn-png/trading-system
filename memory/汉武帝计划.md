## 一、核心时序变革（v8.0灵魂）

### 问题本质

```
旧v7.x：反应型 → "今天看到涨 → 今天买 → 明天卖"
        结果：信号滞后1天，买在涨停潮日，卖在暴跌日

新v8.0：预判型 → "今天看到异动 → 今天买 → 明天涨 → 卖"
        结果：买在启动前夜，卖在拉升日
```

### 时序转换表（每条规则全部-1天）

| 旧v7.x逻辑 | 问题 | 新v8.0逻辑 |
|:----------|:----|:----------|
| 今天板块涨了→追龙二 | 买在涨停潮日 | 今天板块异动(放量小涨) → 埋伏龙二 |
| 今天个股放量突破→买入 | 第2天涨停买不到 | 昨天放量不涨→今天缩量回调→埋伏 |
| 今天最强板块→明天继续 | 第3天分化暴跌 | 今天调整板块→明天可能轮动 |
| 看到涨停了再追 | 封板买不进 | 昨天异动今天缩量→今天埋伏 |
| 评分高的票→推荐 | 评分高=已涨高 | 评分高但还没涨的→推荐 |
| 近5日涨幅前5板块 | 已经是强弩之末 | 近5日异动过但今天调整的板块 |

**一句话：所有买入决策，必须基于昨天或前天的信号，不能基于今天的信号。**

## 二、信号识别（v8.0新增核心）

### 信号分类：把"机会"和"陷阱"分开

```
🚀 真机会信号（在Day -1或Day -2出现）：
  ✅ 放量不涨：量比>3 + 涨幅<2% → 建仓信号
  ✅ 缩量回调：昨天放量涨→今天缩量跌→洗盘完成
  ✅ 抗跌企稳：大盘跌2%+ 它跌<0.5% → 有资金护盘
  ✅ 板块轮动：昨天涨→今天跌2-5% → 明天可能反弹

💀 假机会信号（在Day 0出现，实际是陷阱）：
  ❌ 涨停潮：板块涨停≥3只 → 该卖不该买
  ❌ 板块涨幅>3% → 高潮信号，明天分化
  ❌ 连涨第3天 → 第三天的"强"是出货
  ❌ 舆情沸腾 → 所有人都知道的利好=已price in
```

### 信号时序图

```
Day -2          Day -1          Day 0 (今天)      Day 1 (明天)
放量不涨        缩量回调        放量拉升 ★        冲高或分化
（建仓）        （洗盘）         （启动）          （卖出）
                                     ↑
                             旧系统在这里买（晚了）
                               
Day -2          Day -1          Day 0 (今天)      Day 1 (明天)
板块异动        板块小跌        板块大涨 ★        分化或暴跌
（资金试盘）    （洗盘）         （涨停潮）        （陷阱）
                                     ↑
                             旧系统在这里买（接盘）
```

**v8.0规则：永远买在Day -1（缩量回调/抗跌/异动），永远不买在Day 0（拉升/涨停潮）。**

## 七、选股流程（v8.1改版）

### 每日选股三问

```
第一问（先扫板块）：今天资金在流向哪个板块？
  → 不看科技，先看全市场，医药/消费/金融有没有蓄力
  
第二问：昨天/前天什么票异动过（放量不涨）？
  → 从第一问确定的板块里找 → 今天缩量回调了 → ✅ 埋伏候选
  
第三问（反共识检查）：什么板块所有人都在讨论？
  → 如果是科技 → 先问拥挤度多少 → 拥挤>70%就避开
  
第四问：今天什么票在抗跌（大盘-2%它平盘）？
  → 找到 → 有资金护盘 → ✅ 明天大概率涨
```

### 四问都找不到→今日不推荐

```
❌ 禁止只看半导体/AI/军工（旧习惯）
```
