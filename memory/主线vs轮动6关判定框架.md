## 核心问题

一个板块涨了，怎么知道它是「主线延续」还是「短线轮动」？

## 6关判定法

每关由对应模型独立回答：🟢通过 / 🟡不确定 / 🔴不通过

| 关卡 | 模型 | 问题 | 主线信号 | 轮动信号 |
|:---:|:----|:----|:--------|:--------|
| ① | 刘备 | 有真实业绩/政策/行业催化吗？ | 中报暴增/政策落地/行业拐点 | 纯情绪/无实质利好 |
| ② | 关羽+关平 | 板块结构健康吗？ | 多子板块同步涨 | 仅1-2只涨，其他不跟 |
| ③ | 关羽线4 | 资金持续流入吗？ | 连续多日暗流+大额净流入 | 单日脉冲后消失 |
| ④ | 张飞 | 散户一致看多了吗？ | 还在骂街/懊恼/踏空 | 全网讨论一致看多 |
| ⑤ | 秦始皇 | 大盘环境支持吗？ | 评分>60 上升趋势 | 评分<40 全面收缩 |
| ⑥ | 赵云 | 历史上有过主升行情吗？ | 历史上是主线板块 | 历史上一日游 |

## 判定规则

```
≥4关通过（🟢）→ 主线延续
  策略：持有/买入，不轮动
  执行：诸葛亮持有规则（2周+）
  暂停：刘彻短线轮动规则

<4关通过（🟢）→ 短线轮动
  策略：第2天出/不追
  执行：刘彻轮动规则
  暂停：诸葛亮长持规则
```

## 主线结束的三个条件

当以下任意两条同时出现时，主线确认结束，切换回轮动策略：

```
① 催化兑现完毕（中报出完/政策落地/利好出尽）
② 板块结构从齐涨变分化（仅龙头涨，跟风不涨）
③ 散户从骂街变成一致看多（全网讨论该板块）
```

## 全模型引用规则

```
刘彻：启动前先跑6关判定 → ≥4关=用诸葛亮规则，<4关=用刘彻规则
汉武帝：T+1执行前检查板块是否为当前主线
诸葛亮：DNA评分+6关判定双重确认 → 入候选池
关羽/关平：每日扫描输出子板块结构健康度
张飞：反人性判定结果输入第④关
刘备：催化验证结果输入第①关
秦始皇：大盘评分输入第⑤关
赵云：历史回测数据输入第⑥关
```
